# 流转 (Liuzhuan)

> 跨应用素材暂存中转站：电脑端拖拽暂存 · 手机复制秒达 · 文件双向流转 · 多设备实时同步

[![Build](https://github.com/hxroo6/Liuzhuan/actions/workflows/build.yml/badge.svg)](https://github.com/hxroo6/Liuzhuan/actions/workflows/build.yml)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[English](README_en.md) · 中文

流转是一个**纯局域网**的素材流转工具。电脑端是一个悬浮在屏幕边缘的素材暂存栏（拖拽暂存、即用即拖），安卓端负责把手机上的剪贴板文字、分享的文件实时送到电脑，也能随时把电脑上的素材拉回手机。

**全程不经过任何云端服务器**，数据只在你自己的局域网里流动。

## ✨ 功能

### 电脑端（C# WPF）
- 悬浮侧边栏：拖拽暂存任意文件/图片/文字，即用即拖
- 素材分类：文字 / 图片 / 视频 / 音频 / 文件
- 搜索、删除、撤回（Ctrl+Z）、剪贴板粘贴（Ctrl+V）
- **剪贴板监控（可开关）**：电脑上任意应用复制 → 自动读取剪贴板加载进流转并同步手机
- **配对二维码**：设置菜单一键生成，手机扫码即连（自动填入 IP/端口/口令）
- **UDP 自动发现**：手机一键搜索局域网内的电脑，点选自动填入
- 热区展开 + 位置自愈：鼠标贴近屏幕右缘自动展开；多屏拔插自动归位
- 设置菜单：本机 IP 显示 + 刷新、口令管理、已连接设备列表、开机自启动

### 安卓端（Kotlin + Compose，Android 16+）
- **后台复制秒达（LSPosed 模式）**：在任意 App（含微信）复制 → 直接推送到电脑，无需切回、完全无感。模块 hook 系统剪贴板写入路径，事件驱动、不读剪贴板、零轮询，对原 App 只旁路观察零干扰（需 Root + LSPosed，见下文「两种模式」）
- **图片/文件复制同步**：复制图片或文件 → 自动上传电脑素材库
- **发送文件**：发送页「加入文件」选任意格式/大小 → 局域网流式直传（恒定内存，GB 级文件约 1 分钟）
- **复制到电脑（标准模式）**：复制后切回流转 → 瞬间推送剪贴板最新内容；暴露文本选区的 App（浏览器、系统编辑器）后台复制自动推送
- **文本选择菜单**：长按选中文字 → 系统菜单选「流转」→ 不经剪贴板直发电脑
- **后台自动发送开关**：发送页可随时关闭"复制自动发送"（默认开）
- **接收页**：实时同步电脑端最近素材（WS 推送增量，零轮询、超省电）
- **链路诊断**：连接页日志区实时显示「复制捕获 → 发送」各环节状态与历史，无需连接电脑即可排查问题
- **单击素材**：文字 → 复制剪贴板；图片/视频/音频 → 保存到手机相册
- **分享上传**：任意 App 分享文字/文件 → 流转 → 自动上传电脑
- **扫码连接**：扫电脑屏幕上的配对二维码，一步连接（免输 IP/口令）
- **自动发现**：一键搜索局域网电脑，点选填入 IP
- **暂停重连**：连接失败自动重连中可一键暂停，避免死循环
- **日志双击复制**：连接页日志区双击复制全部日志，方便排查
- **多设备**：多台手机/平板可同时连接，任意设备操作全设备同步

### 安全
- 局域网直连，无任何云端依赖
- 口令 SHA256 哈希认证（WS 握手 + HTTP 文件上传/下载鉴权）
- 文件下载/上传必须携带口令哈希，拒绝未授权访问
- 剪贴板内容不出局域网，适合敏感工作流

## 📦 架构

```
┌────────────┐   WS 8899 (控制面：握手/心跳/文字/列表/广播)   ┌──────────────┐
│  安卓端 N 台 ├──────────────────────────────────────────────►│              │
└────────────┘                                                │   电脑端流转   │
┌────────────┐   HTTP 8900 (数据面：文件上传/下载，带鉴权)     │  (WS 服务器)   │
│  安卓端 N 台 ├──────────────────────────────────────────────►│              │
└────────────┘                                                └──────────────┘
```

- 控制面：Fleck WebSocket，多会话 + 全广播（天然支持多设备）
- 数据面：极简 HTTP 服务器（TcpListener 手写，避免 http.sys 权限坑），文件流式传输
- 同步策略：**WS 推送增量 + 首次全量拉取**，零轮询、零额外连接，功耗≈0

## 🚀 快速开始

### 电脑端（Windows 10/11 x64）

```bash
cd Liuzhuan
dotnet publish -c Release -r win-x64 --self-contained true -o dist
./dist/Liuzhuan.exe
```

启动后：设置菜单 → 查看本机 IP / 生成口令。默认端口：控制面 8899、数据面 8900。

### 安卓端

构建要求见 [BUILDING.md](BUILDING.md)。

1. 构建安装 APK，首次启动允许通知权限（**要求 Android 16+**）
2. 连接页：**扫码连接**（扫电脑端设置菜单的配对二维码，一步连接）或 **搜索电脑**（自动发现列表点选）或手动填 IP/端口/口令
3. 点连接 → 自动引导开启无障碍（剪贴板监控）→ 返回自动重连
4. 发送：任意 App 复制后切回流转即秒发；长按选中文字 → 菜单「流转」直发；发送页「加入文件」可传任意格式/大小文件；分享菜单上传
5. （可选，Root 用户）LSPosed → 启用流转模块 → 勾选微信等 App → force-stop 目标 App 重开 → **后台复制秒达**（见「两种模式」）

> 两端需在同一局域网（同一 Wi-Fi 或电脑开热点给手机）。
>
> 💡 电脑端设置菜单 →「配对二维码」可随时弹窗；「剪贴板监控」开启后电脑复制也自动收藏。

### 关于「后台复制自动发送」的两种模式

**LSPosed 模式（推荐，需 Root 设备）**：在 LSPosed Manager 中启用流转模块并勾选微信等目标 App，即可实现**任意 App 后台复制秒达**。原理：模块 hook 系统剪贴板**写入路径**（`setPrimaryClip`），事件驱动截获内容——不读剪贴板、不轮询，从根上绕开 Android 10+ 的读取焦点限制；且只旁路观察，不修改不阻断，对原 App 复制功能零干扰。激活后需 force-stop 目标 App 重新打开（已运行进程不注入）。

**标准模式（无需 Root）**：Android 10+ 出于安全禁止无焦点 App 读取剪贴板（各厂商执行严格度不同，实测 ColorOS 严格拒绝）。流转提供三条合规路径：

| 场景 | 做法 | 体验 |
|---|---|---|
| 复制后切回流转 | 什么都不用做，切回瞬间自动推送剪贴板最新内容 | 最顺手，推荐 |
| 微信等受限制的 App | 长按选中文字 → 系统菜单选「流转」 | 不经剪贴板直发，零切换 |
| 浏览器/编辑器等 | 后台复制即自动推送（这类 App 暴露文本选区，无障碍可直接捕获） | 无感自动 |

App 内置链路诊断（连接页日志区），可随时查看「复制捕获 → 发送」各环节的真实状态。

## 🔌 通信协议（摘要）

| 类型 | 方向 | 说明 |
|------|------|------|
| `hello` / `welcome` | C↔S | 握手认证（SHA256 口令哈希） |
| `sync_text` / `clipboard_push` | C→S | 文字素材推送 |
| `list_sync` / `list_data` | C↔S | 最近素材列表拉取（50 条摘要） |
| `item_added` | S→C | 新素材广播（全设备） |
| `get_item` / `item_data` | C↔S | 素材详情（文字全文 / 文件下载地址） |
| `heartbeat` / `ack` | C↔S | 心跳 / 回执 |
| `GET /file/{id}?auth=` | C→S | 文件下载（HTTP 8900） |
| `POST /upload?name=&auth=` | C→S | 文件上传（HTTP 8900） |
| UDP 8901 `LIUZHUAN_DISCOVER` | C→S | 设备自动发现（广播应答） |
