# 流转 (Liuzhuan)

> 跨应用素材暂存中转站：电脑端拖拽暂存 · 手机复制秒达 · 文件双向流转 · 多设备实时同步

[![Build](https://github.com/hxroo6/Liuzhuan/actions/workflows/build.yml/badge.svg)](https://github.com/hxroo6/Liuzhuan/actions/workflows/build.yml)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[English](README_en.md) · 中文

流转是一个**纯局域网**的素材流转工具。电脑端是一个悬浮在屏幕边缘的素材暂存栏（拖拽暂存、即用即拖），安卓端负责把手机上的剪贴板文字、分享的文件实时送到电脑，也能随时把电脑上的素材拉回手机。

**全程不经过任何云端服务器**，数据只在你自己的局域网里流动。

## 手机麦克风（v1.9.0，实验功能）

- 手机连接页点**“扫码连接全部功能”**，扫电脑常规配对码一次：素材握手成功后自动获取新的麦克风邀请、前台开启采音并接通转发；首次只需允许系统录音权限，无需再扫麦克风码或点电脑“开始转发”。普通启动/后台重连不自动开麦。
- 电脑按已保存的虚拟设备ID启用音频，首次可识别标准CABLE Input/Output；没有驱动或设备失效时会提示先在“设置 → 手机麦克风”配置，素材功能仍可用。已连素材后，从左上音波图进入麦克风页点“连接当前电脑麦克风”即可直接重连，不必重新扫码。
- 麦克风页返回后回到连接首页，**真实音波图缩在左上角**，显示待命、传音、安静和暂停；点击重新展开，返回不停止采音。小音波图仅在可见时更新，不使整页随音量刷新。
- 手机确认开启后**持续待命，没有15分钟或闲置时限**。支持手机暂停/允许再次请求/结束，电脑手动转发/停止/结束手机会话/关闭服务。停止转发不等于停采；主动结束、断线、撤权或系统阻断才释放，断线/重启不自动开麦。电脑锁定/睡眠仍关闭音频服务。
- 首版按用户要求为**局域网明文音频**，端口8902，短时单次扫码口令；不保存录音。没有内置ASR、没有MicYou/AndroidMic应用依赖，也不自动安装虚拟驱动或更改系统默认设备。Codex识别仍遵循其自身联网与服务行为。
- 手机新增实际采音波形、dBFS电平、采集/发送帧数与60秒本机试音；本机试音不连接电脑、不发送或保存录音。电脑新增接收电平及“仅诊断收音”模式，清楚区分手机收音、网络到达和虚拟设备输出。
- 默认“安静省流量”：音量足够才发PCM，安静时只留轻量心跳。灵敏/标准/抗噪三档，200ms开头缓存、500ms尾音，安静批量读取100ms；可关闭后连续发送。它按音量判断，不识别人声，手机仍持续采音；实际省电比例、弱声/噪声环境待专项测量。
- 电脑新增**实验自动跟随**：先校准一次原听写“开始→结束”，验证独立Codex录音会话后再勾选，绑定本次手机连接。停止、手机暂停、断线或身份变化自动退出；默认关闭、不监听鼠标、不更改系统默认音频。记住本机设备ID，设备失效需重新选择。
- 电脑素材栏标题旁新增可点击的真实音频波形，直接打开麦克风设置；手机省流量开关与三档灵敏度自动保存，扫码、连接当前电脑和本机试音统一读取，下次开启会话生效。
- 麦克风和收发二级面板支持下拉关闭，滚动内容到顶部后可继续下拉，关闭面板不停止采音或任务。电脑麦克风页可展开链路诊断并复制脱敏统计，区分接收和播放端读取；暂停后按两端提示恢复，无需重扫。
- 原手机→局域网→CABLE→Codex手动听写已通过，当前Codex录音会话0→1→0已现场确认；M42一次扫码和左上音波图按[交付记录](docs/performance/PHONE_MIC_M42_2026-10-17.md)分别标明验收范围，长时间待命/功耗仍需实测。Windows系统播放使用实体扬声器，流转写入CABLE Input，Codex读取CABLE Output。现已包含在上方v1.9.0下载中。

## v1.8.0：发送回执、文件校验与图片预设（本地版本）

- **自动文字发送回执**：手机等待电脑素材库登记回执，区分等待、已登记与未确认。支持新协议的两端使用稳定请求编号和有限重试；断线、超时不再直接丢弃事件。重试受隐私规则、目标电脑和事件期限约束，旧电脑只提交一次并显示未确认，避免盲目重复。
- **更多 → 素材内容完整性检查**，或文件素材右键 **检查文件内容**：主动后台计算 SHA-256，区分未记录、正常、内容变化、缺失与读取失败，支持取消。首次记录或接受外部编辑后的新内容需明确确认；不修改原文件，不自动把变化判定为损坏。
- **处理图片 → 常用预设**：命名保存 PNG/JPEG、最长边和 JPEG 质量，选择后填入参数；支持更新、重命名、删除，最多 20 个。选择预设不会立即处理图片，输出仍为独立副本。
- 文件校验基线和图片预设随迁移包恢复，旧索引和旧包仍可读取。路径或类型改变、后台任务过期时不会把旧结果用于新来源。

回执与幂等记录是有界的进程内状态，不能保证程序重启后永久恰好一次；“已登记”表示电脑接收登记成功，不等于磁盘事务持久化。文件校验仅判断相对已确认基线的内容变化，不能恢复丢失或损坏文件。真实手机后台复制、混合 DPI 和不同网络环境仍需独立验收；APK 覆盖安装后，到无障碍设置关闭→重新开启流转服务。

## v1.7.0：来源修复、隐私控制与图片处理（本地版本）

- **更多 → 素材来源管理与重新定位**：原文件被移动或暂时无法访问时，保留索引、收藏、标签与备注，并显示失效标记。可逐条选择新文件，或后台扫描具体文件夹、检查候选路径后批量应用；歧义不自动绑定，扫描支持取消。已被旧版本移除的索引无法凭空恢复。
- **设置 → 剪贴板隐私与应用排除**：电脑按进程名称（如 `WeChat.exe`）排除；手机在连接页「自动同步」卡片按包名排除。两端支持暂停 15 分钟、1 小时和手动恢复。名单非空时，无法确认来源的自动采集也会跳过；手机已捕获但未发送的自动事件会随暂停/规则变更失效。手动发送、分享及接收仍可使用，已保存素材不自动删除，不能承诺识别所有密码。
- **选中图片 → 右键 → 处理图片**：批量生成 PNG/JPEG，按最长边保持比例缩小，设置 JPEG 质量；透明转 JPEG 使用白底。输出独立文件夹，显示实际尺寸、字节大小与逐项失败，保留原件，支持取消；尺寸不放大，压缩后可能比原图更大。
- 图片处理仅输出主图/首帧，会清除拍摄元数据；HEIC/HEIF 等依赖 Windows 可用解码器，不能把动画或矢量当作无损格式转换。大型原生编解码无法立即打断，取消在可控阶段生效。
- 电脑应用排除规则随迁移包恢复，临时暂停期限不迁移；文字文件迁移保留完整原文文件。重新定位后的缩略图任务校验来源与加载版本，避免旧回调覆盖新图。

请更新两端；APK 覆盖安装后，到无障碍设置关闭→重新开启流转服务。自动检查和离屏界面检查已覆盖本轮功能，手机实机后台复制、混合 DPI 拖动与不同网络环境仍需单独验收。竞品来源及后续方向见 [产品路线](docs/PRODUCT_ROADMAP.md)。

## v1.5.0：分组、标签和备注（本地版本）

- 选择素材后点击底部 **整理…**、按 **F2** 或使用右键菜单。每条素材可设置一个分组、多个标签和备注；输入新名称即可创建分组，留空表示未分组。
- 批量编辑只修改勾选的字段，其他信息保留；标签支持追加、替换和移除。Ctrl+Enter 保存，取消不修改素材。
- 顶部分组、标签可与分类和搜索一起筛选；搜索也能找到备注。卡片显示整理摘要，悬停可查看详细信息。
- 「移除当前结果」只处理当前筛选出的非收藏素材，可撤回；收藏页对应操作只取消当前结果的收藏。
- 整理信息随素材库保存，并包含在「迁移与备份」中。兼容旧素材库和旧迁移包；要在换机后保留这些信息，两台电脑请使用 v1.5.0 或更新版本。

分组最多 48 字符；每条素材最多 20 个标签、每个最多 32 字符；备注最多 4000 字符。分组和标签不区分大小写，标签用逗号或分号分隔。分组列表来自当前素材，空分组不会单独保留。此功能用于电脑端整理；手机仍同步原素材内容。普通「另存」生成可直接使用的文件，换机复用整理信息请导出迁移包。

- 控制面：Fleck WebSocket，多会话 + 全广播（天然支持多设备）

```bash
cd Liuzhuan
dotnet publish -c Release -r win-x64 --self-contained true -o dist
./dist/Liuzhuan.exe
```

启动后：设置菜单 → 查看本机 IP / 生成口令。默认端口：控制面 8899、数据面 8900。

#### HEIC 图片自动转换（v1.1.1）

设置 → **接收 HEIC 自动转换**：

| 选项 | 行为 |
|---|---|
| PNG（默认） | 转为无损 PNG，保留图片分辨率 |
| JPEG | 转为质量 95 的 JPEG，透明区域使用白色背景 |
| 关闭 | 原样接收，不转换 |

设置会保存，仅对之后从手机收到的图片生效；旧图片可重新发送。转换后的文件进入素材库并同步到手机，原始文件仍保留在上传目录。普通图片不变。

转换依赖 Windows 的 HEIF/HEVC 解码支持；缺少解码器或转换失败时，会提示并保留收到的原文件。转换输出静态主图，不保证保留多帧、HDR 或全部元数据。PNG/JPEG 是实际重新编码，不是仅修改后缀。

### 安卓端

构建要求见 [BUILDING.md](BUILDING.md)。

1. 构建安装 APK，首次启动允许通知权限（**要求 Android 16+**）
2. 连接页：**扫码连接**（扫电脑端设置菜单的配对二维码，一步连接）或 **搜索电脑**（自动发现列表点选）或手动填 IP/端口/口令
3. 点连接 → 自动引导开启无障碍（剪贴板监控）→ 返回自动重连
4. 发送：任意 App 复制后切回流转即秒发；长按选中文字 → 菜单「流转」直发；发送页「加入文件」可传任意格式/大小文件；分享菜单上传
5. （可选，Root 用户）LSPosed → 启用流转模块 → 勾选微信等 App → force-stop 目标 App 重开 → **后台复制秒达**（见「两种模式」）

>
> 💡 电脑端设置菜单 →「配对二维码」可随时弹窗；「剪贴板监控」开启后电脑复制也自动收藏。

### 关于「后台复制自动发送」的两种模式

**LSPosed 模式（推荐，需 Root 设备）**：在 LSPosed Manager 中启用流转模块并勾选微信等目标 App，即可实现**任意 App 后台复制秒达**。原理：模块 hook 系统剪贴板**写入路径**（`setPrimaryClip`），事件驱动截获内容——不读剪贴板、不轮询，从根上绕开 Android 10+ 的读取焦点限制；且只旁路观察，不修改不阻断，对原 App 复制功能零干扰。激活后需 force-stop 目标 App 重新打开（已运行进程不注入）。

**标准模式（无需 Root）**：Android 10+ 出于安全禁止无焦点 App 读取剪贴板（各厂商执行严格度不同，实测 ColorOS 严格拒绝）。流转提供三条合规路径：

| 场景 | 做法 | 体验 |
|---|---|---|
| 复制后切回流转 | 什么都不用做，切回瞬间自动推送剪贴板最新内容 | 最顺手，推荐 |
| 微信等受限制的 App | 长按选中文字 → 系统菜单选「流转」 | 不经剪贴板直发，零切换 |
| 浏览器/编辑器等 | 后台复制即自动推送（这类 App 暴露文本选区，无障碍可直接捕获） | 无感自动 |

App 内置链路诊断（连接页日志区），可随时查看「复制捕获 → 发送」各环节的真实状态。

## 🔌 通信协议（摘要）

| 类型 | 方向 | 说明 |
|------|------|------|
| `hello` / `welcome` | C↔S | 握手认证（SHA256 口令哈希） |
| `sync_text` / `clipboard_push` | C→S | 文字素材推送 |
| `list_sync` / `list_data` | C↔S | 最近素材列表拉取（50 条摘要） |
| `item_added` | S→C | 新素材广播（全设备） |
| `get_item` / `item_data` | C↔S | 素材详情（文字全文 / 文件下载地址） |
| `heartbeat` / `ack` | C↔S | 心跳 / 回执 |
| `GET /file/{id}?auth=` | C→S | 文件下载（HTTP 8900） |
| `POST /upload?name=&auth=` | C→S | 文件上传（HTTP 8900） |
| UDP 8901 `LIUZHUAN_DISCOVER` | C→S | 设备自动发现（广播应答） |
