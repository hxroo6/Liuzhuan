## 📌 主文案（250 字，可直接发朋友圈/微博）

《流转》开源了！这是我一个人写了大半个月的跨设备素材中转工具。

痛点：手机和电脑之间传文字、图片、文件，要么开微信文件传输助手，要么插数据线，烦。而它：手机复制 → 电脑秒出现；电脑拖拽暂存 → 手机随时取；图片、视频、文件双向秒传，多台设备实时同步。

最硬核的是隐私：全程纯局域网直连，不经过任何云端服务器，不用注册账号，口令哈希认证。电脑端 C# WPF，安卓端 Kotlin Compose，架构干净，已跑通完整 CI 自动构建。

如果你也受够了"传个文件还要绕一圈"的日常，点个 ⭐ Star 支持一下，也欢迎 Fork、提 Issue、共建。你的一个 Star，就是独立开发者继续走下去的动力。
