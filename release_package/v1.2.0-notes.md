## 中文

本次同时更新 Windows 和 Android：统一青绿界面，完善收发反馈，并修复局域网配对和手机搜索问题。

- 电脑悬浮素材栏优化布局、分类、按压和展开收起反馈；新增图片/文字空格快捷预览。
- 手机连接、发送、接收页面重新梳理；接收页提供缩略图和按需列表加载，减少切页及进度更新的界面负担。
- 两端新增本次运行的收发任务、进度及结果；手机失败任务可重试。上传收齐并登记后确认，图片下载完成后才显示在相册。
- 二维码排除 Wintun/VPN 等虚拟网卡，支持选择实际局域网地址；发现服务优先匹配手机子网，手机采用实际回包源地址。
- 手机搜索在后台线程执行，处理失败并防止重复点击；移除整页位移/透明度动画。
- 保留 HEIC 按内容识别及自动 PNG/JPEG 转换，保留原图。

### 下载与升级

- Windows 10/11 x64：下载 `Liuzhuan-v1.2.0-windows-x64.zip`。退出旧版，替换 `app` 目录，保留同级 `data` 目录，然后运行 `app/Liuzhuan.exe`。已包含 .NET 运行库。
- Android 16+：下载 `Liuzhuan-v1.2.0-android.apk`，与旧版同签名，可覆盖安装。安装后到无障碍设置关闭→重新开启流转服务。
- 请同时更新两端，重新扫描电脑二维码，替换此前保存的错误虚拟网卡地址。
- 安装包不包含本机素材、日志、配对口令或签名密钥。SHA-256 见同页校验文件。

### 验证与限制

两端编译、APK 签名验证通过。上一阶段网卡选择、二维码解码、UDP 后台搜索、取消释放和错误传播自动检查通过。手机扫码互通、搜索崩溃堆栈及切页帧率尚未完成真机验收。任务记录仅保留本次运行，重试会重新传输整个文件。HEIC 转换仍需 Windows HEIF/HEVC 解码支持。

## English

This release updates both Windows and Android with a unified teal interface, clearer transfer feedback, and LAN pairing/discovery fixes.

- Refined desktop panel layout, categories, press feedback, and expand/collapse transitions; Space opens image/text quick preview.
- Reworked Android Connect, Send, and Receive pages, photo thumbnails, and lazy material rows; reduced whole-screen updates from transfer progress.
- Session transfer tasks, progress, and outcomes on both ends, with retry on Android. Uploads are acknowledged after full receipt and registration; gallery images appear only after saving completes.
- QR pairing excludes Wintun/VPN virtual adapters and supports LAN address selection. Discovery considers the phone subnet and uses the actual response source address on Android.
- Android discovery runs off the UI thread, handles failures, and prevents duplicate searches. Full-page translation/opacity transitions were removed.
- Retains content-based HEIC detection and automatic PNG/JPEG conversion while preserving originals.

### Download and upgrade

- Windows 10/11 x64: download `Liuzhuan-v1.2.0-windows-x64.zip`, exit the old app, replace its `app` directory, retain the sibling `data` directory, and run `app/Liuzhuan.exe`. The .NET runtime is included.
- Android 16+: install `Liuzhuan-v1.2.0-android.apk` over the existing app (same signing certificate), then turn its accessibility service off and back on.
- Update both ends and scan a fresh desktop QR code to replace any previously saved virtual-adapter address.
- Packages exclude local materials, logs, pairing credentials, and signing keys. SHA-256 checksums are included as a separate asset.

### Validation and limitations

Both builds and APK signature verification passed. Previous automated checks covered adapter selection, QR decoding, background UDP discovery, cancellation cleanup, and error propagation. Real-device pairing, phone crash traces, and frame-rate acceptance remain pending. Transfer history lasts for the current session; retries resend the full file. HEIC conversion requires Windows HEIF/HEVC decoding support.
