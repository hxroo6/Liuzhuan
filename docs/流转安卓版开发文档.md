## 1. 项目概述

### 1.1 定义
「流转」安卓版是 Windows 端流转的**局域网伴侣**：手机素材（文件/剪贴板/文字/截图/照片/视频）秒传电脑流转；电脑素材可反向推送手机。全程局域网直连，不上云，手机后台低功耗常驻。

### 1.2 核心场景
| # | 场景 | 验收目标 |
|---|------|----------|
| S1 | 手机复制文字 → 电脑流转出现 | ≤2 秒，自动 |
| S2 | 手机相册/文件 → 传电脑 | 流转出现缩略图 |
| S3 | 手机任意文件 → 传电脑 | 与拖入体验一致 |
| S4 | 电脑素材 → 发手机 | 手机可保存/分享 |
| S5 | 后台常驻 8 小时 | 耗电 ≤2% |
| S6 | 未连接时 | 优雅降级，不影响本机 |

## 2. 系统架构

### 2.1 拓扑（定稿：Hub 模式）

```
┌────────────────┐   局域网 (Wi-Fi/热点)    ┌─────────────────┐
│   安卓端 (客户端) │◄──────────────────────►│ 电脑端流转 (Hub)  │
│ 填 IP:8899+口令  │   WS 长连接 + HTTP 传输  │ 监听 8899+8900   │
└────────────────┘                          └─────────────────┘
```

- 电脑端常驻监听，多台手机可同时连接
- 素材统一汇聚到电脑端 data/（流转的定位）
- 手机端仅客户端 → 后台保活/低功耗最简

### 2.2 端口规划
| 端口 | 用途 | 说明 |
|------|------|------|
| **8899** | 控制面（WebSocket） | 握手/认证/消息/心跳 |
| **8900** | 数据面（HTTP） | 文件上传/下载（分块+断点） |

> 手机端只需填一个端口（8899），数据端口自动 +1。均可在电脑端设置修改（文件端口跟随主端口）。

### 2.3 通信分层
```
应用层    JSON 消息协议（WS 文本帧）
会话层    Fleck WebSocket 长连接（心跳保活，多会话并发）
数据面    HTTP 文件通道（分块 1MB / 断点续传 / sha256 校验）
传输层    TCP（同一局域网，明文）
```

### 2.4 同步模型（定稿：仅新增）
```
手机 ──新增──▶ 电脑：实时推送（剪贴板监控 / 手动发送 / 分享菜单）
电脑 ──新增──▶ 手机：推送（右键"发送到手机"）
删除 / 编辑 / 收藏：❌ 不联动（保持简单）

去重：素材以手机端生成 UUID 标识；电脑端按 UUID 幂等忽略重复
落库：电脑端复用 CreateTextItem / CreateFromPath → DataStore.Add → RefreshView
      （即以"本地新增"的方式同步进流转，新卡片样式一致）
```

## 3. 通信协议（定稿 v1）

### 3.1 消息帧（WS 文本，UTF-8 JSON）
```json
{
  "v": 1,
  "type": "sync_text",
  "id": "uuid",
  "ts": 1722600000,
  "device": "Pixel 8",
  "data": {}
}
```

### 3.2 认证握手
```
1. 手机连接 WS:  /ws?auth=<sha256(口令)>&device=Pixel8&ts=<unix>
2. 电脑校验:     ① ts 与服务器时间差 < 5min（防重放）
                ② sha256(口令) 匹配（口令即权限，无设备白名单）
3. 成功 → welcome {serverVersion, features:["text","file"], sessionId}
   失败 → auth_fail {reason: "口令错误" | "时间偏差"}
4. 手机端保存 (sessionId) 用于文件通道绑定
```

### 3.3 消息类型（定稿）
| type | 方向 | 负载 | 说明 |
|------|------|------|------|
| `hello` | C→S | {auth, device, ts} | 握手 |
| `welcome` | S→C | {serverVersion, features, sessionId} | 认证通过 |
| `auth_fail` | S→C | {reason} | 认证失败 |
| `heartbeat` | 双向 | {t} | 保活（间隔自适应 30s~5min） |
| `sync_text` | 双向 | {content, title?, source} | 同步文字素材 |
| `sync_file_meta` | 双向 | {name, size, sha256, mime, source} | 文件元数据 |
| `file_ack` | 双向 | {fileId, offset, exists} | 接收确认（断点/查重） |
| `transfer_done` | 双向 | {fileId} | 传输完成 |
| `clipboard_push` | C→S | {content, app, ts} | 剪贴板监控推送 |
| `bye` | 双向 | {} | 优雅断开 |

### 3.4 文件传输流程
```
发送方 → 接收方: sync_file_meta {id, name, size, sha256}
接收方 → 发送方: file_ack {fileId, offset:0} 或 {exists:true}（同 sha256 直接跳过）
发送方 → 接收方: HTTP
   上传: POST /api/upload?fileId=&offset=N   body=原始字节块(≤1MB)
   下载: GET  /api/download?fileId=&offset=N
   （文件端口 = 主端口+1）
接收方:        按 offset 写盘 → 收齐 → 校验 sha256 → transfer_done
               → 落库（电脑端：走现有新增流程；手机端：存 Download/流转）
```

## 4. 安卓端设计（Android 16+ / Kotlin + Compose）

### 4.1 工程结构
```
app/
├── MainActivity.kt              // Compose 壳（3 Tab 导航）
├── ui/
│   ├── ConnectScreen.kt         // Tab1 连接卡片
│   ├── ItemsScreen.kt           // Tab2 已同步素材记录
│   └── SendScreen.kt            // Tab3 发送面板 + FAB
├── net/
│   ├── LanClient.kt             // 连接管理：握手/心跳/重连(指数退避)/消息分发
│   ├── Proto.kt                 // 消息编解码（kotlinx.serialization）
│   └── FileTransfer.kt          // HTTP 分块上传/下载 + 进度回调
├── clipboard/
│   └── ClipMonitorService.kt    // AccessibilityService：复制事件 → 读剪贴板 → 推送
├── core/
│   ├── AppForegroundService.kt  // 前台服务（dataSync）保活 + 连接持有
│   ├── SettingsStore.kt         // DataStore：IP/端口/口令/设备名/心跳
│   └── SyncHistory.kt           // Room：同步记录（可选）
└── share/
    └── ShareReceiverActivity.kt // ACTION_SEND 分享入口（截图/文件/文字）
```

### 4.2 连接管理（LanClient）
```
状态机:  Idle → Connecting → Authenticating → Connected → (Lost) → Reconnecting
重连:    指数退避 1s→2s→4s→…→上限 5min；CONNECTIVITY_CHANGE 广播 → 立即重连
心跳:    连接期 30s；连续空闲 10min → 5min；收到任何消息即重置计时
会话:    断线保留 (IP,端口,口令,设备名)；提供"一键重连"入口
```

### 4.3 剪贴板监控（定稿：无障碍）
```
ClipMonitorService (AccessibilityService):
  onAccessibilityEvent(TYPE_VIEW_FOCUSED / TYPE_WINDOW_CONTENT_CHANGED):
    · 防抖：同内容 2s 内不重复推送
    · 读 ClipboardManager 文本 → 非空 → clipboard_push {content, app:包名}
    · 仅推送文本（图片剪贴板 Android 无法后台读，S1 只保证文字）⚠️ 已知边界
权限引导：首次开启引导页 → 跳无障碍设置 → 校验已启用
```
> **已知边界**：Android 剪贴板图片后台不可读，剪贴板监控仅覆盖文字；截图/照片走"分享菜单"路径补足。

### 4.4 后台低功耗（定稿）
```
L0 前台服务 foregroundServiceType="dataSync"（Android 14+ 声明 FOREGROUND_SERVICE_DATA_SYNC 权限）
   通知：低优先级 + "运行中"文案（不可滑动关闭）
L1 心跳自适应（见 4.2）
L2 Doze：引导加入电池优化白名单（Settings.ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS）
L3 厂商后台限制引导页（小米/华为/OPPO/vivo 特定设置入口）⚠️ 列表驱动
L4 剪贴板监控仅在复制事件时激活，无事件休眠
目标：8h 纯心跳耗电 ≤2%
```

### 4.5 发送入口
| 入口 | 实现 |
|------|------|
| 分享菜单 | ShareReceiverActivity 接收 ACTION_SEND（text/*, image/*, */*）→ 直接连发 |
| 发送面板 | SAF 选文件 / 系统相册选择器 / 文本输入框 / 当前剪贴板一键发送 |
| 剪贴板 | 自动监控推送（文字） |

### 4.6 UI 精要（小巧精致）
- Material 3 动态色 + 深色主题，单 Activity 架构
- Tab1 连接卡片：IP/端口/口令输入、连接状态灯（● 红/黄/绿）、最近连接历史、二维码扫描（可选，M4）
- Tab2 同步记录：时间线列表（文字预览/缩略图/时间/设备）
- Tab3 发送：大按钮 + FAB
- APK 目标 ≤15MB

## 5. 电脑端改造

### 5.1 新增模块 `Services/Lan/`
```
LanServer.cs         // 生命周期：Start(port,password)/Stop；持有 Fleck + HttpListener
WsHub.cs             // Fleck WebSocketServer；会话表 ConcurrentDictionary<sessionId, IWebSocketConnection>
AuthService.cs       // sha256(口令) 校验 + ts 防重放（±5min）
FileChannel.cs       // HttpListener 8899+1=8900：/api/upload /api/download（分块+断点）
InboxSink.cs         // 上传落盘 data/inbox/ → sha256 校验 → 转正式素材
Pusher.cs            // 向指定/全部手机推送（text/file）
```

### 5.2 与现有代码接入点
| 接入点 | 动作 |
|--------|------|
| `DataStore.Add` | Lan 收到素材 → CreateFromPath/CreateTextItem（source=手机）→ Add → RefreshView |
| `SettingsBtn_Click` | 加「局域网服务器」组：开关 / 端口 / 口令(生成·显示·修改) / 已连接设备数 |
| 右键菜单 | 「发送到手机」→ Pusher 推送（文件先经 FileChannel 发手机） |
| `Window_Closing` | LanServer.Stop()（释放端口） |

### 5.3 依赖
- `Fleck`（WS） + `QRCoder`（M4 配对二维码，可选）

## 6. 安全（定稿：明文+口令）
| 威胁 | 对策 |
|------|------|
| 同网段他人连接 | 6 位随机纯数字口令（电脑端生成，可改）；sha256 哈希认证不传明文 |
| 重放攻击 | hello.ts 与服务器时间差 <5min 校验 |
| 数据嗅探 | 家庭可信网络可接受；文档注明风险 ⚠️（若日后上公共网络，升级 AES 为阶段外项） |
| 新设备 | 凭口令自动接入（决策 #6），无白名单 |

## 9. 验收标准（总）

- [ ] 手机复制文字 → ≤2s 出现在电脑流转（新卡片样式=本地新增）
- [ ] 手机经分享菜单/发送面板发照片 → 电脑流转显示缩略图，有进度
- [ ] 电脑右键「发送到手机」→ 手机可保存/分享
- [ ] 断网 5min → 自动重连不丢消息（UUID 幂等）
- [ ] 后台 8h 黑屏无操作 → 耗电 ≤2%，连接存活
- [ ] 错误口令被拒；正确口令自动接入（无弹窗）
- [ ] APK ≤15MB；电脑端仍为单文件绿色版
- [ ] 仅新增同步：删除/编辑/收藏互不影响
