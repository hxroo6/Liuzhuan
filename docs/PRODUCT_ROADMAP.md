# 流转：竞品参考与完善方向

调研日期：2026-10-03。以下以产品官网公开功能为依据，借鉴工作流程；未安装、购买或复制竞品代码。

| 工具与官方来源 | 值得参考的功能 | 流转的取舍 |
|---|---|---|
| [Eagle](https://en.eagle.cool/) | 智能文件夹按条件归类、标签、批处理和快速预览 | 已有标签/备注/批量/预览；v1.6 增加保存条件的常用筛选 |
| [LocalSend 协议](https://github.com/localsend/protocol) | 明确传输会话、接受/拒绝状态与可选 SHA-256；HTTPS 传输 | v1.8 补齐自动文字回执和有限重试、素材内容校验；保留流转既有协议，加密传输另做升级 |
| [Dropover 图片动作](https://dropoverapp.com/kb/instant-actions) | 缩放、转换、压缩、清除元数据；[预设操作](https://dropoverapp.com/kb/custom-actions)减少重复输入 | v1.7 提供批量 PNG/JPEG、最长边和质量；v1.8 增加图片预设 |
| [Paste 隐私设置](https://pasteapp.io/help/exclude-apps) | Mac 端应用排除与定时暂停；既有历史不因新排除规则自动消失 | v1.7 两端应用排除、暂停和恢复；明确未知来源边界，不猜测所有密码 |

| [KDE Connect 官方源码说明](https://github.com/KDE/kdeconnect-kde/blob/master/README.md) | 跨设备剪贴板、文件与链接分享，TLS 通信和设备配对 | 保持素材流转主线；设备信任和 TLS 作为下一轮协议专项，不扩展远控或通知权限 |

## 已实施：v1.6.0

1. 常用筛选：命名保存分类、分组、标签和搜索；更新条件、重命名、删除；新增匹配素材自动出现，迁移包含规则。
2. 稳定发现：UDP 固定 8901，应答返回实际 WS 端口；取消、超时和服务停启保留明确边界。
3. 接收增量可靠性：三类变化统一验序，缺口等待权威快照；重连/空库基线正确，撤回按原素材时间排序，快照与发送在同一所属线程调度。

## 已实施：v1.7.0

1. 来源管理：失效索引继续保留，后台检查/扫描；候选先展示再确认，单项或整批校验成功后更新；同 ID 和整理信息保留，旧缩略图任务失效。
2. 隐私控制：两端定时暂停和应用排除；在读/解码与发送之前检查，手机断线队列和自动文件重试同样受限。配置错误明确阻止自动采集，显式发送保持可用。
3. 图片动作：批量缩小、JPEG/PNG、JPEG 质量、实际结果与单项错误；独立副本、首帧、清除拍摄元数据、源哈希不变和取消边界。

## 本轮已实施：v1.8.0

1. 自动文字回执：稳定请求编号、等待电脑登记成功、有限重试、服务器有界幂等；隐私规则与目标约束仍生效，旧端不盲重发。
2. 文件完整性：按需后台计算 SHA-256、取消、明确展示未记录/匹配/变化/缺失/失败；确认后记录或更新基线，迁移保留基线，源变化使旧检查失效。
3. 图片处理预设：保存、选用、更新、重命名、删除格式/尺寸/质量组合；独立素材库文件原子保存，迁移恢复，选择参数不自动处理原件。

## 后续优先级建议（未实施）

1. **安全传输升级**：TLS 与扫码建立设备信任；需成对升级协议、证书生命周期与兼容策略，独立验收后交付。
2. **大文件分段恢复与端到端校验**：中断后继续传输、传输字节哈希；与本轮素材库基线检查分开，不能把现有 HTTP 重传当作断点续传。
3. **历史保留与清理预览**：可选保留周期、容量提醒、先展示候选；区分素材索引与源文件，确认后才移除，收藏默认保护。
4. **持久回执与设备管理**：当前回执/outbox 是进程内有界状态；继续完善崩溃恢复和设备信任身份，不能宣称跨重启永久恰好一次。

双端实机测试、混合 DPI 拖动和不同路由器网络环境，继续与自动检查分开报告。公开版本仍按用户明确的推送/Release 请求发布。
