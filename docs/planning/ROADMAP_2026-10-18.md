# 流转下一阶段规划

原规划日期：2026-10-18。最新对齐：2026-10-24，M57 / v1.20.0 本地实现。用户已授权本轮优化与新增，**N01 OCR 明确排除，不实施**；N04 继续不含右键菜单。本轮真实手机/网络/音频验收尚未完成，GitHub 与 Releases 尚未推送。

M57 更新：

- **恢复与切库：** DataStore 固定构造时的库根；默认/导入/保留库统计，切换在下次启动执行。索引历史正常保留最多10份、合计128MiB、单份64MiB，最多每5分钟留存一次旧索引；差异先预览，恢复前备份当前索引，过时计划不覆盖后续编辑。仅恢复索引，不回滚原件、配置、身份或回执。
- **项目暂存：** 显式扫描项目准备原件；保护当前素材、Undo 和续传引用。未引用原件可分批移入独立项目回收区并恢复，坏绑定/链接/不完整扫描阻止回收。准备与合入提交共用锁；不删除绑定，不递归删除或覆盖恢复。
- **手机项目包：** 手机发起电脑侧选中素材打包、下载，以及已收集 ZIP 的电脑侧预览/确认合入。复用项目包校验、稳定目标与可靠传输，不新增第二条配对链；不等于手机本地独立 ZIP 库或整库设置迁移。
- **离线增强：** 手机显式固定原件，按原电脑/库/来源版本核验并受配额限制；默认512MiB，可设128MiB–2GiB、最多200项，不自动下载全库。完整索引支持有界增量，有序校验后原子提交；换运行代次、过期游标或缺口退回完整索引流程，持久草稿独立保留。
- **性能与可靠发送：** 输入合并、不可变查询快照、后台大库筛选及查询修订缓存；来源状态、缩略图、时长和基线不触发无关搜索重建。网络缩略图限制长边/并发/输出及缓存。修补目录与发送链的可靠登记顺序，继续落盘后确认，不降低校验或 fsync。
- **优先级与限速：** 两端保存发送/接收优先与方向限速，可选为麦克风让路；文件数据/准入有预算和等待老化，控制、回执、音频不进入文件限速。偏好不等于抢占当前任务，也不代表实测省电比例。
- **维护：** PC 本地工程已升级到 .NET 10，Android 构建插件已升级；Android 16+ 支持范围保持不变。构建及隔离检查与设备验收分别报告，不能据本地实现宣称所有设备场景已通过。

## 4. 单独评估与继续暂缓的方向

- **Android 兼容范围：** 目前仅 Android 16+。若面向 B 站更多用户，值得优先评估 Android 13–15。先盘点 API 与前台服务/无障碍差异、选代表设备验证，再确定最低版本；不是直接修改 minSdk 的小任务。
- **运行时维护：** 原稿建议的迁移已在M57本地实施：PC目标为 .NET 10，Android AGP为8.10.1。旧的“.NET 7待迁移”仅为历史基线；现阶段继续核对WPF/音频/网络依赖、打包及目标Windows，不能以工程升级代替设备兼容验收。[微软支持政策](https://dotnet.microsoft.com/en-us/platform/support/policy/dotnet-core)保留作为维护参考。
- **TLS / 长期设备信任：** 当前是用户明确允许的可信局域网明文首版，未实施安全升级。它是未来独立阶段，不是本轮擅自补上的遗漏；不将稳定 UUID 宣传为设备安全认证。
- **移动数据版：** 按此前要求继续暂缓，原方案见 [REMOTE_SYNC_PLAN.md](../REMOTE_SYNC_PLAN.md)。未来需统一端点、信任/加密、计费网络策略和续传，不能只放开蜂窝网络判断。
- **自研虚拟音频驱动、全平台、通知/远控、内置大模型：** 暂不放到近期主线，避免驱动维护、权限和产品范围扩张掩盖素材与音频链路的现有缺口。

## 5. 建议开发批次
