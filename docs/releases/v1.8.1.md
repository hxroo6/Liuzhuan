## 中文

本次发布安卓 v1.8.1 启动修复，配套电脑端 v1.8.0，并公开此前 v1.4–v1.8 的素材管理与同步改进。

### 安卓启动与后台复制
- 现场发现 Android 16 + LSPosed Irena 1.9.2 在注入可调试进程时发生原生崩溃，系统启动画面表现为卡住。日常交付改用不可调试的 Distribution，同源码、同签名、不启用 R8，不停用后台复制 Hook。
- 原手机和原框架中已验证冷启动、搜索电脑、扫码连接、三个页面切换、素材快照和手动文字登记。微信后台两次复制完整经过 Hook→广播→电脑登记回执，约 42 ms / 63 ms，重复广播正确去重；用户实测确认正常。此前环境为何由可用变为失败仍未核实，不能推广为所有 ROM 的兼容保证。
- CI 检查实际 APK 的调试标记、模块入口和广播 action，避免再次误发可调试包。CI 未配置私人 keystore 时使用测试证书；此页 APK 为已验签的本地正式签名交付包。

### 电脑端累积改进
- 批量选择、复制、收藏、多文件拖出和另存；分组、标签、备注及常用筛选，支持迁移复用。
- 失效素材保留与来源重新定位；剪贴板应用排除和定时暂停；图片 PNG/JPEG 转换、尺寸/质量处理和常用预设，保留原件。
- 文件内容 SHA-256 校验；安卓自动文字登记回执、有限重试和有界去重；快照/增量同步与固定发现端口。回执表示电脑登记成功，不等于磁盘事务持久化；不保证程序重启后永久恰好一次。
- 保留迁移与备份、HEIC 自动转换和拖动/贴边稳定性修复。HEIC 解码仍依赖 Windows 可用编解码器，跨屏与混合 DPI 需实机验证。

### 下载与升级
- `Liuzhuan-v1.8.1-android.apk`：Android 16+，正式签名、不可调试。覆盖安装后，到无障碍设置关闭→重新开启流转服务。LSPosed 用户保持模块启用及目标应用作用域，模块更新后需重启目标应用进程。
- `Liuzhuan-v1.8.0-windows-x64.zip`：Windows 10/11 x64，自包含运行时，解压运行 `app/Liuzhuan.exe`。旧电脑升级先退出流转、替换 `app`，保留同级 `data`；不导入公开程序包作为素材迁移包。
- `Liuzhuan-v1.8.1-SHA256SUMS.txt`：下载后可用 `Get-FileHash -Algorithm SHA256` 校验。

公开源码与程序包不包含个人联系方式、手机日志、设备地址、配对口令、用户素材、配置备份或签名私钥；保留项目账号形式的版权归属。自行导出的迁移包包含素材和口令，未加密，请仅在自己的设备间传递。本次只对当前待发布内容和安装包脱敏，不改写已有公开 Git 历史或旧版 Releases。

## English

This release delivers the Android v1.8.1 startup fix with PC v1.8.0, including previously local material-management and synchronization improvements from v1.4–v1.8.

### Android startup and background copying
- The tested Android 16 / LSPosed Irena 1.9.2 environment crashed while injecting a debuggable process, leaving an apparently frozen splash screen. Daily delivery now uses non-debuggable Distribution with the same application source and signing certificate, no R8, and the clipboard Hook retained.
- Cold startup, PC discovery, QR connection, all three pages, material snapshots, and manual text receipts passed on the original phone and framework. Two WeChat copies with Liuzhuan in the background completed Hook→broadcast→PC registration receipt in about 42 ms / 63 ms; duplicate broadcasts were suppressed. The user confirmed normal operation. The historical environment change remains unverified, and these results do not guarantee every ROM.
- CI checks the actual APK's debugging flag, module entry point, and receiver action. CI without the private keystore uses a test certificate; this release APK uses the verified local production certificate.

### Cumulative PC improvements
- Batch selection, copying, favorites, multi-file dragging and export; groups, tags, notes and saved filters included in migration archives.
- Missing-source retention and relocation; clipboard application exclusions and timed pauses; independent PNG/JPEG image outputs with size/quality controls and reusable presets.
- SHA-256 content checks, automatic text registration receipts, bounded retries/deduplication, snapshot/incremental synchronization and fixed-port discovery. Registered does not mean a durable disk transaction; deduplication is not permanent across process restarts.
- Existing migration/backup, automatic HEIC conversion and drag/edge-docking fixes are included. HEIC still requires available Windows codecs; mixed-DPI and multi-monitor behavior needs separate device acceptance.

### Downloads and upgrade
- `Liuzhuan-v1.8.1-android.apk`: Android 16+, production certificate, non-debuggable. Install over the existing app, then toggle the Liuzhuan accessibility service off and on. Keep the LSPosed module and target scopes enabled; restart target app processes after updating the module.
- `Liuzhuan-v1.8.0-windows-x64.zip`: Windows 10/11 x64, self-contained. Extract and run `app/Liuzhuan.exe`. Exit Liuzhuan before replacing `app`, and preserve the adjacent `data` folder. This program archive is not a material migration archive.
- `Liuzhuan-v1.8.1-SHA256SUMS.txt`: verify downloads with `Get-FileHash -Algorithm SHA256`.

Public source and packages exclude personal contact details, phone logs, device addresses, pairing credentials, user materials, configuration backups and signing private keys. Copyright attribution uses the project account. User-created migration archives contain materials and passwords without encryption; keep them private. This pass sanitizes the current publication and packages; existing public Git history and older releases are retained.
