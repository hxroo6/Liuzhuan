## 中文

### 新增迁移与备份
- 设置 → 迁移与备份（配置 + 素材），导出 `.liuzhuan.zip`，在新电脑导入。
- 包含原文件、文字、收藏、缩略图、HEIC/剪贴板监控设置、局域网端口与口令、开机自启偏好；导入后自动重建本地路径。
- 文件大小与 SHA-256 校验通过后才准备切换，退出并重新打开生效。原素材库与原配置指针保留，不合并或覆盖旧库。
- 支持后台进度与取消，缺失原文件、损坏包和不安全路径明确报错。

### 菜单与说明
- 主菜单和 HEIC 子菜单统一深色模板、13 号字体、清晰勾选和悬停状态。
- 中英文 README 补充迁移、升级与回退步骤。当前源码移除个人联系方式、固定测试口令及本机地址样例，旧截图和旧程序包不再随当前源码分发。

### 下载与使用
下载 `Liuzhuan-v1.3.0-windows-x64.zip`，解压后运行 `app/Liuzhuan.exe`。支持 Windows 10/11 x64，已包含 .NET。原电脑升级时先退出流转，替换 app 目录，保留同级 data 目录。

旧、新两台电脑均需使用 v1.3.0 才有迁移入口。先在旧电脑导出，拷到新电脑导入，完成后退出并重新打开，再让手机重新扫码。程序下载 ZIP 不含个人素材；你自行导出的迁移 ZIP 包含素材与配对口令且未加密，请妥善保管。

本次不更新安卓，继续使用 [v1.2.0 APK](https://github.com/hxroo6/Liuzhuan/releases/download/v1.2.0/Liuzhuan-v1.2.0-android.apk)。如果覆盖安装 APK，请到无障碍设置关闭→重新开启流转服务。

验证：21 项迁移自动检查、网卡/二维码检查、Windows 自包含构建通过。迁移已用隔离目录模拟旧路径不可用验证，未进行第二台实体电脑验收。HEIC 解码仍需 Windows 对应编解码器。

## English

### Migration and backup
- Open Settings → 迁移与备份（配置 + 素材） to export a `.liuzhuan.zip`, then import it on another PC.
- Includes original files, text, favorites, thumbnails, HEIC/clipboard preferences, LAN port/password, and startup preference. File paths are remapped on import.
- File sizes and SHA-256 hashes are verified before queuing activation. Exit and reopen to switch libraries. The old library and configuration pointer remain intact; libraries are not merged.
- Background progress and cancellation, with explicit errors for missing originals, damaged archives, and unsafe paths.

### Menus and documentation
- Consistent dark settings/submenu templates, readable 13-point text, checkmarks, and hover feedback.
- Bilingual migration, upgrade, and rollback instructions. Personal contact details, fixed test credentials, and machine-specific address examples were removed from the current source; old screenshots and binaries are no longer included in the current source tree.

### Download and use
Download `Liuzhuan-v1.3.0-windows-x64.zip`, extract it, and run `app/Liuzhuan.exe`. Windows 10/11 x64; .NET is included. Exit before upgrading, replace app, and retain the sibling data directory.

Use v1.3.0 on both PCs for migration. Export on the old PC, import on the new PC, exit and reopen, then scan a fresh QR code from the phone. Public program ZIPs contain no personal materials; your own migration ZIP contains materials and pairing credentials and is not encrypted.

Android is unchanged; keep using the [v1.2.0 APK](https://github.com/hxroo6/Liuzhuan/releases/download/v1.2.0/Liuzhuan-v1.2.0-android.apk). If installing it again, turn the accessibility service off and back on.

Validation: 21 migration checks, LAN/QR checks, and self-contained Windows publishing passed. Relocation was tested with isolated directories and unavailable old paths, not a second physical PC. HEIC still requires the corresponding Windows codecs.

SHA-256: see `Liuzhuan-v1.3.0-SHA256SUMS.txt`.
