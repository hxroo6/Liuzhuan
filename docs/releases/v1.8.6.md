## 中文

发布 Android v1.8.6（versionCode 11），包含热点连接修复和历史连接。电脑端继续提供未经改动的 PC v1.8.1 安装包，两端既有协议保持兼容。手机移动数据远程同步暂缓，本版本仍为局域网工具。

### 热点连接修复

- 修复电脑已连接手机热点、扫码目标正确，安卓仍显示「等待局域网恢复」而不连接的问题。此前网络检测遗漏手机作为热点提供方的状态。
- 使用 Android 16 公共热点接口回调与原网络回调合并状态，事件驱动，不新增轮询或权限。
- 电脑连上手机热点后，使用该网卡地址重新生成二维码。切换 Wi-Fi/热点会改变地址，旧历史地址不保证继续可用。

### 历史连接

- 安卓连接页增加「历史连接」，只记录成功鉴权的电脑地址，最多 20 条，按最近连接排序；相同地址和端口更新而不重复增加。
- 点选重连、删除单条、确认清空。删除历史不影响当前连接、素材或原有当前目标设置。
- 历史口令采用本机 Android Keystore 的 AES-256/GCM 密钥加密，不展示明文。这里仅指新历史凭据，不代表既有当前目标设置或用户导出的迁移包已加密。
- 历史损坏或密钥不可用时提示重新扫码；恢复连接保留省电、隐私和文件管理器偏好。历史不能替代远程组网或公网中转。

### 下载与升级

- `Liuzhuan-v1.8.6-android.apk`：Android 16+，正式签名、不可调试的 Distribution；沿用原证书，可覆盖安装。随后在无障碍设置将流转服务**关闭→重新开启**；LSPosed 保留模块与应用作用域。
- `Liuzhuan-v1.8.1-windows-x64.zip`：沿用上一版电脑包，已有 PC v1.8.1 的用户无需重复升级。Windows 10/11 x64，解压运行 `app/Liuzhuan.exe`；替换时先退出程序，替换整个 `app` 并保留同级 `data`。
- `Liuzhuan-v1.8.6-SHA256SUMS.txt`：包含两端安装包的 SHA-256，可使用 `Get-FileHash -Algorithm SHA256` 校验。

此前统一接收目录、打开接收位置、两端暂停/取消以及可选均衡省电均保留。尚不支持真正字节断点续传或跨进程恢复任务，Android 继续会从头传输。

### 验证范围与脱敏

开发阶段已通过：M37 的 46 项功耗/传输及 28 项素材同步检查；M38 的 22 项历史模型/JSON/实际 AES-GCM 检查、44 项回执/HTTP/socket 及 14 项电脑 WS 回归。各阶段有重叠，不作为相加总数。Android Debug / Distribution / lint 与正式签名检查已通过；没有为此次发布重新构建安装包。

现场已验证手机热点到电脑建立连接；历史成功保存、进程重启后保留、点选重连和素材重新同步通过。热点现场使用此前扫码保存的目标，没有重新摄像头扫码验收。用户随后要求停止测试，删除/清空交互、GB 级速度、长期功耗和所有 ROM 兼容性未验证，不继续操作手机。详见 [热点记录](../performance/HOTSPOT_CONNECTION_2026-10-14.md)和[历史记录](../performance/CONNECTION_HISTORY_2026-10-14.md)。

公开源码、待推送提交信息和程序包已脱敏审计；不发布个人联系方式、实际设备地址、配对凭据、诊断原始日志、用户素材/配置、备份、签名私钥或 PDB。测试地址及测试口令仅为隔离测试数据。APK 只包含公开签名证书，不包含签名私钥；现有 Git 历史和旧 Releases 保留。

## English

Android v1.8.6 (versionCode 11) includes phone-hotspot connection fixes and connection history. The unchanged PC v1.8.1 package remains compatible with the existing protocol. Remote synchronization over cellular data is deferred; this release remains a LAN tool.

### Phone hotspot connectivity

- Fixes Android waiting for LAN connectivity even when the PC has joined the phone hotspot and the scanned target is correct. Earlier network detection missed the phone acting as the hotspot host.
- Public Android 16 tethering callbacks and existing network callbacks merge connectivity state without new polling or permissions.
- Generate a fresh QR code for the PC hotspot-facing adapter. Switching between Wi-Fi and hotspot networks can change addresses; old history entries may become unreachable.

### Connection history

- The connection page remembers up to 20 successfully authenticated endpoints, newest first. Reconnecting to the same host and port updates the entry rather than adding a duplicate.
- Select to reconnect, delete individual entries, or confirm clearing history. Deletion does not affect the active session, materials or existing current-target settings.
- Historical credentials use an Android Keystore AES-256/GCM key and are not displayed as plaintext. This protection applies to new history records; existing current-target settings and user-exported migration archives are not newly encrypted.
- Corrupt records or unavailable keys prompt a fresh scan. Recalling a connection preserves power, privacy and file-manager preferences. History does not provide remote networking by itself.

### Downloads and upgrade

- `Liuzhuan-v1.8.6-android.apk`: Android 16+, non-debuggable Distribution with the existing production certificate. Install over the previous app, then toggle Liuzhuan accessibility **off and back on**. Keep LSPosed module scopes enabled.
- `Liuzhuan-v1.8.1-windows-x64.zip`: unchanged desktop package; existing PC v1.8.1 users do not need another update. Windows 10/11 x64. Extract and run `app/Liuzhuan.exe`; exit the app before replacing the entire `app` directory and preserve adjacent `data`.
- `Liuzhuan-v1.8.6-SHA256SUMS.txt`: SHA-256 checksums for both packages; verify using `Get-FileHash -Algorithm SHA256`.

Earlier fixed receive-folder browsing, transfer pause/cancel and optional Balanced power mode remain included. Byte-offset resume and task recovery across process restarts remain unsupported; Android continue restarts the full transfer.

### Validation and sanitization

Development validation passed: M37 had 46 power/transfer and 28 material-sync checks; M38 had 22 history/JSON/actual AES-GCM checks, 44 receipt/HTTP/socket checks and 14 PC WebSocket regressions. Stages overlap and are not an additive total. Android Debug / Distribution / lint and production-signature checks passed. This publication reuses the delivered APK without rebuilding it.

Device acceptance covered hotspot-to-PC connectivity, successful history recording, persistence after process restart, recalled connection and fresh material synchronization. Hotspot acceptance reused a previously scanned target rather than scanning with the camera again. Further testing stopped at the user's request. Delete/clear interactions, GB-scale throughput, sustained battery use and all-ROM compatibility remain unverified. See the [hotspot record](../performance/HOTSPOT_CONNECTION_2026-10-14.md) and [history record](../performance/CONNECTION_HISTORY_2026-10-14.md).

Public source, unpublished commit metadata and packages were audited. Personal contacts, actual device addresses, pairing credentials, raw diagnostics, materials/settings, backups, signing private keys and PDBs are excluded. Test addresses and passwords are isolated test data. The APK contains the public signing certificate, not its private key. Existing Git history and older releases remain available.
