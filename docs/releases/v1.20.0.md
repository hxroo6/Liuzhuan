# 流转 Liuzhuan v1.20.0 — 源码更新 / Source update

更新日期：2026-10-25。本文说明自公开v1.9.0以来的源码变化；v1.20.0安装包尚未上传Releases，当前下载页中的v1.9.0不包含下列新增功能。请按[构建指南](../../BUILDING.md)构建并同时更新两端。

## 中文

### 麦克风配置更容易恢复

- 手机左上音波图 →「电脑音频」→「检查并修复电脑音频」。已配对电脑会实际检查并应用可安全识别的虚拟设备对，返回结果后由手机前台按既有授权流程重连。驱动重装或重启导致旧设备ID失效时，无需反复操作电脑下拉框。
- 「仅检查」不改配置。自动修复核对驱动标识和同一PnP设备关联，排除16声道端口；多组设备、驱动缺失或设备信息不完整时给出下一步提示。不会把实体扬声器当作虚拟麦克风，不安装驱动，也不更改Windows默认播放、音量或静音。
- 实际收到非静音音频且虚拟播放端读取后，自动保存已验证的流转设备组合。外放和听写都正常时，可确认保存完整配置对照；误配、静音和设备失效会提示核对。恢复不会自动恢复录音许可或自动跟随。
- 保留即时待命与节能连接：节能模式结束采音、音频心跳和相关保活锁；用户在前台明确开启时可临时收音。

### 素材与收发更完整

- 手机支持完整素材库的搜索、分类、分组、标签、收藏、批量整理和常用搜索；离线索引及待同步草稿按电脑和库隔离，冲突需要核对。
- 主动保留选中原件供离线打开，提供容量配额、校验、重试与取消固定。已有完整离线索引可增量更新，服务器重启或游标失效时退回完整保存。
- 文件分块校验、断点续传、任务/待发文字/回执持久化；重启或断线后按原目标恢复。双端可按方向筛选任务，调整优先级、限速，或在传音频时让行。
- 目录订阅、自动整理规则与快捷收集延续素材原件保护；手机扫码固定竖屏，麦克风与收发面板可下拉关闭。

### 电脑素材库更稳妥

- 分类查询、搜索和缩略图使用有界后台工作，降低大库切换时的界面阻塞；来源状态变化不重复触发完整筛选。
- 新增索引历史比较、恢复及切库计划，下次启动生效。项目暂存支持先扫描再回收，并可恢复；不会递归清理未知目录。
- 支持项目ZIP导出、校验预览后合入现有库；手机可请求电脑打包、下载或预览合入。另有只读重复文件检查、容量及历史管理。
- PC升级WPF/.NET 10，Android使用JDK 21、AGP 8.10.1、API 36。Android最低版本仍为16，正式签名和剪贴板Hook路径保持不变。

### 使用与验证边界

本轮两端构建和专项回归通过，手机发起电脑修复及重连已完成本次设备现场确认；其它ROM、弱网、多任务音频、识别首尾字和实际电池消耗仍需对应验收。万条合成素材测试不是实屏帧率或所有设备的速度承诺。[详细验证记录](../performance/M57_RELIABILITY_OFFLINE_2026-10-24.md)

流转仍仅面向可信局域网/手机热点，当前没有公网或移动流量模式，音频为明文传输。不含本地OCR；不分发VB-CABLE驱动，其下载和许可独立于流转。离线原件是私有明文副本、旧副本是历史快照；索引恢复不能找回已丢失原件。项目打包作业是有界进程内任务，重启后需重新发起，生成ZIP的下载使用原可靠传输。

升级请保留data目录及自定义库，电脑使用完整app目录；安卓同签名覆盖安装后，到无障碍设置关闭→重新开启流转服务，并重启LSPosed作用域内来源应用。自行构建/CI的测试签名可能无法覆盖已有正式安装，请勿为此卸载或清除现有数据。

## English

These notes cover source changes since public v1.9.0. v1.20.0 installers have not been uploaded; build both peers using the [building guide](../../BUILDING.md).

### Easier microphone recovery

- Open the phone waveform → Computer audio → Check and repair. The authenticated PC applies a safely identified virtual pair and returns the result; the foreground phone reconnects through the existing permission flow. This addresses stale saved endpoint IDs after device re-enumeration.
- Check only leaves configuration unchanged. Repair verifies the driver identity and shared PnP device, excludes 16-channel endpoints, and reports ambiguous or missing devices. It neither selects physical speakers as a virtual bridge nor installs drivers or changes Windows defaults, volume or mute.
- Real non-silent PCM and render consumption establish a saved virtual-route reference. Confirm working playback and dictation to save a complete configuration reference. Suspicious changes produce guidance; recovery never restores recording consent or automatic following.
- Energy-saving mode releases capture, audio heartbeats and related wake locks while retaining materials connectivity. A foreground user action can open a temporary microphone session.

### Libraries and transfers

- Browse, search, filter and organize the full PC library from Android, including batch metadata editing and saved searches. Offline indexes and drafts are isolated by computer/library, with explicit conflict review.
- Pin selected originals for verified offline access with quotas, retries and unpinning. Complete offline indexes can update incrementally, falling back to a full save after a server restart or expired cursor.
- Transfers support block checksums, byte-offset resume, and persistent tasks, pending text and receipts. Both peers expose task filtering, directional priorities/rate limits and optional yielding during audio forwarding.
- Folder subscriptions, organization rules, quick collection, portrait scanning and dismissible microphone/transfer panels are included.

### Desktop reliability

- Bounded background queries and thumbnail processing reduce large-library UI work. Source-status notifications do not repeatedly invalidate the full filter.
- Compare retained index versions and schedule restart-time recovery/library switching. Scan and recycle unreferenced project staging files with restoration support; unknown directories are not recursively removed.
- Export project ZIPs and verify/preview before merging into an existing library, including requests initiated from the phone. Read-only duplicate checks and capacity/history tools are available.
- Windows uses WPF/.NET 10; Android uses JDK 21, AGP 8.10.1 and API 36. Android 16 remains the minimum. Signing and clipboard Hook boundaries are preserved.

### Validation and limits

Both builds and focused regressions passed. Phone-triggered PC repair and microphone reconnection were verified on the current devices; other ROMs, weak networks, concurrent audio/files, ASR word boundaries and battery consumption remain separate acceptance work. Synthetic scale measurements are not display frame-rate guarantees. See the [validation record](../performance/M57_RELIABILITY_OFFLINE_2026-10-24.md).

Trusted LAN/phone-hotspot only; no cellular or public Internet mode, and audio remains plaintext. Local OCR is excluded. VB-CABLE is a separate, independently licensed driver and is not distributed with Liuzhuan. Offline originals are private plaintext historical copies; index recovery does not recover missing source files. Project-package jobs are bounded in-process operations, while downloads of generated ZIPs use the durable transfer path.

Keep existing data/custom libraries when upgrading and retain the full desktop app directory. After a same-signature APK upgrade, toggle accessibility off/on and restart LSPosed-scoped source apps. Self-built or CI test signatures may not replace an existing official installation; do not uninstall or clear data merely to work around this.
