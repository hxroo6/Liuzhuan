# 流转 Liuzhuan v1.9.0

## 中文

本版新增手机麦克风实验功能，并保留现有局域网素材、剪贴板与文件收发功能。

- 手机扫码一次即可完成素材与麦克风握手；首次需允许系统录音权限。有权限时自动前台采音并请求转发，无需第二次扫码或电脑手动开始。
- 手机连接成功且完成素材鉴权后，电脑素材栏自动展开并显示“手机连接成功 · 素材同步已就绪”；频繁重连限频提示，不抢键盘焦点。此提示不代表麦克风或语音识别成功。
- 电脑标题音波可点击进入麦克风设置；手机顶部小音波可展开。两端波形来自实际PCM，不是装饰动画。
- 麦克风/收发面板支持下拉关闭，不结束现有采音或传输。省流量与灵敏度自动保存，扫码、连接当前电脑与试音共用，下次开启会话生效。
- 安静时不发送音频，仅保留心跳；持续会话没有15分钟或闲置截止。停止转发仍采音，结束会话才释放麦克风；断线或应用重启不自动开麦。
- 增加脱敏链路诊断，分别显示接收帧和播放回调读取量；Codex自动跟随为默认关闭、需校准的实验功能。

设备方向：流转输出到CABLE Input，Codex输入选择CABLE Output。Windows系统播放建议使用实体扬声器，避免提示音混入。流转不自动安装驱动或改变默认音频设备。

### 升级与验证范围

下载Windows完整ZIP，退出旧流转后替换整个app目录，保留原data目录；Android APK采用原有正式签名覆盖安装，之后请到无障碍设置关闭→重新开启流转服务。发布包不含个人配置、素材、日志、密钥或驱动。

已验证原手机手动听写链、一次扫码握手、有声/安静门控、持续待命、偏好跨进程保存及本机采音参数。自动跟随完整联动、不同ROM、来电/锁屏、弱网/大文件并发、首尾字和实际功耗仍需专项验证。音频目前是明文局域网WS8902，仅用于可信局域网；没有公网或移动流量模式。不支持字节断点续传，暂停后继续从头传输。Android仅支持Android16及以上。

## English

This release adds an experimental phone microphone bridge while preserving LAN materials, clipboard sync and file transfers.

- Scan the regular PC pairing QR once to authenticate materials and negotiate the microphone. Grant the Android recording permission on first use; no second QR or manual PC start is required.
- After material authentication, the PC panel expands and displays a connection-success message. Reconnect storms are rate-limited, without stealing keyboard focus. This confirms material connectivity, not microphone delivery or ASR.
- Click the desktop title waveform to open microphone settings. Android provides a compact waveform and swipe-down microphone/transfer panels; dismissal keeps capture and transfers running.
- Traffic-saving and sensitivity preferences persist across app restarts and are shared by scanning, reconnecting and local testing. Changes apply when the next session starts.
- Quiet periods send only heartbeats; authorized sessions have no idle or 15-minute timeout. Stopping forwarding leaves capture active; ending releases it. Disconnect/relaunch never automatically restarts recording.
- Sanitized diagnostics distinguish received frames from PCM consumed by the playback callback. Codex automatic following remains experimental, off by default and requires calibration.

### External audio driver

VB-CABLE is not bundled, modified or redistributed. Users should install it separately from the [official VB-Audio website](https://vb-audio.com/Cable/). It is independently licensed Donationware by VB-Audio Software; professional/business use requires payment under the [official licensing policy](https://vb-audio.com/Services/licensing.htm) and [general terms](https://shop.vb-audio.com/en/content/3-Terms-of-use). Liuzhuan's open-source license does not cover VB-CABLE.

Liuzhuan writes CABLE Input; Codex reads CABLE Output. Keep Windows system playback on physical speakers. Liuzhuan does not install drivers or change default audio devices.

### Upgrade and limitations

Exit the desktop app before replacing the complete app directory; preserve the adjacent data directory. Install the APK over the existing application, then toggle its accessibility service off and on. Packages exclude personal data, settings, logs, private keys and drivers.

The original manual dictation chain, single-scan handshake, energy gating, standby, preference persistence and local capture configuration were tested. Complete automatic-following acceptance, other ROMs, calls/lock-screen behavior, network/file-transfer concurrency, word boundaries and battery savings remain unverified. Audio is deliberately plaintext on trusted LAN port8902; no public Internet/cellular mode. Byte-offset resume is unsupported. Android16+ only.
