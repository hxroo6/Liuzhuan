## 1. 安装与连接

### 准备两端

- **Windows 10/11 x64：** 下载 Releases 中的 Windows ZIP，完整解压，运行 `app/Liuzhuan.exe`。运行数据默认位于 `app` 旁的 `data` 文件夹，勿误删。
- **Android 16+：** 下载 Releases 中的 APK 安装。按需允许通知、扫码相机权限；手机麦克风另需录音权限。
- **网络：** 两端连同一 Wi-Fi，或手机开热点、电脑连接该热点。当前不支持公网或移动流量远程连接。

### 选择一种连接方式

| 方式 | 操作 | 麦克风行为 |
|---|---|---|
| 扫码连接全部功能 | 电脑开启局域网服务器，打开配对二维码；手机连接页扫码 | 完成素材连接后尝试音频连接，首次请求录音权限；无虚拟设备时提示配置，素材仍可用 |
| 搜索或手动连接 | 手机搜索电脑并点选填入地址，或手填 IP、连接端口；输入电脑显示的口令后连接 | 不因普通素材连接自动采音；需要时从音波图进入麦克风页主动连接 |
| 历史连接 | 手机点「历史连接」，选择曾成功连接的地址 | 重连素材；断线后不会自动恢复开麦 |

电脑可从设置或托盘菜单查看口令、地址与配对二维码。不要公开二维码或把口令放进反馈截图。

### 手机热点连接

1. 手机打开热点，让电脑连接。
2. 在电脑二维码窗口选择**连接手机热点的实际网卡地址**，重新生成二维码。
3. 手机重新扫码。换网前保存的历史地址可能已经失效。

如果电脑有 VPN、虚拟网卡或多个网口，选择能被当前手机访问的电脑地址，不要仅凭地址看起来像内网就选用它。部分路由器的访客网络／客户端隔离也会阻止设备互通。

默认端口：素材连接 TCP **8899**、文件 TCP **8900**、发现 UDP **8901**、可选麦克风 TCP **8902**。自定义素材连接端口后，文件端口为其加一，发现端口仍是 8901。防火墙只需放行所用功能在可信专用网络上的访问，不要直接关闭整个防火墙。

## 2. 文字与剪贴板

**先试手动发送，再配置自动同步。** 手机「发送」页输入并发送文字；电脑出现素材，说明基本连接正常。

### 普通手机，无需 Root

1. 如需自动捕获，按应用提示启用流转无障碍服务，并确认连接页「自动同步」已开启。
2. 在其他应用复制文字，再切回流转，发送最新剪贴板内容。
3. 也可选中文字，在系统文字选择菜单点「流转」；或在其他应用分享文字／文件给流转。

Android 限制后台读取剪贴板。某些应用暴露的文字选区可由无障碍捕获，但不能保证所有应用后台复制都自动发送；微信等受限场景可用分享、文字选择菜单或复制后切回。

### 已 Root 且装有 LSPosed

在 LSPosed 启用流转模块，勾选需要自动同步的目标应用，然后**强制停止并重新打开目标应用**。此模式旁路观察剪贴板写入，不轮询，也不修改来源应用的复制结果。Root 本身不等于已经启用模块和作用域。

### 暂停与排除

- 电脑：设置 →「剪贴板隐私与应用排除」，按进程名称配置。
- 手机：连接页「自动同步」卡片，按应用包名配置。
- 支持暂停 15 分钟、1 小时和手动恢复；两端规则分别设置。
- 排除名单非空时，无法确认来源的自动采集也会跳过。手动发送、分享和接收仍可用；排除不会删除已保存素材，也不能撤回已经发出的内容。
- 「均衡省电」默认关闭；开启后空闲允许休眠，锁屏同步可能稍慢，具体功耗未量化。

## 3. 文件收发与保存路径

**手机 → 电脑：** 发送页添加附件，或从文件管理器／其他应用分享给流转。电脑收到后会登记到素材栏。

**电脑 → 手机：** 将文件拖入电脑素材栏，手机「接收」页出现条目后点击下载。新下载文件统一保存在 `内部存储 / Download / Liuzhuan`，目录在首次接收时创建；旧文件保留原位置。

两端打开「收发」可查看任务、本机恢复记录、进度、速度和结果。手机下拉关闭收发面板不会中止任务。

**M57传输策略：** 在收发页展开策略，选择均衡／发送优先／接收优先，分别设置本机发送、接收总限速（0为不限速，上限100 MiB/s）。勾选音频让行后，流转实际转发麦克风时每方向最多1 MiB/s。设置在本机记住并用于正在传输及排队任务，不改变暂停、取消或校验规则；最多同时传输两项，优先级不是无限抢占。

M55新增名称/方向/状态搜索，以及发送、接收方向筛选。「进行中」包含等待确认及正在停止；「待处理」包含暂停、失败、过期或等待恢复；「已结束」包含成功与取消，汇总会分开显示。筛选只影响当前列表，不会自动重试或取消任务；搜索范围是本机保留的历史，不是全部正文。

电脑「更多 → 查找内容相同的文件」可检查当前素材库中有文件来源的条目。打开后点击「开始检查」才读取文件；先按大小预筛，再比较SHA-256，选择分组查看各来源并打开所在位置。缺失、占用或检查中变化的文件单独提示；可取消。该功能只核对相同字节，不判断图片相似度，不改基线、不合并索引或删除原文件；逻辑重复量不等于实际可释放磁盘空间。手机本轮没有远程重复扫描入口。

| 操作 | 实际行为 |
|---|---|
| 安卓暂停／继续 | M48 新协议关闭当前 I/O 并保留已确认字节；继续从断点开始。旧版对端从头重传 |
| 电脑暂停／继续 | M48 新协议持久保存暂停状态并通知手机，不依赖长时间保留连接；旧协议仍限 90 秒 |
| 取消 | 中止可取消的传输阶段；已提交文字或已进入文件登记阶段无法撤回 |
| 打开接收目录 | 调用文件管理器浏览保存位置，不是重新选择保存目录 |

Android 可选择支持目录浏览的文件管理器，保存路径始终固定；若管理器不支持定位会提示更换应用，不弹出目录选择器。Windows 可自定义文件管理器 EXE 与 `{folder}` 参数模板，该偏好只保存在当前电脑。

**M48 / v1.11.0 需两端一起更新。** 新任务支持分块与完整 SHA-256、字节断点、重启恢复；未完成下载只留在手机私有区，校验后发布到固定接收目录。电脑「已发送」在收到手机保存回执后完成。具体恢复边界见下方「可靠收发与文字待发」。


### 可靠收发与文字待发（M48 / v1.11.0）

两端一起更新后自动协商，无需再扫一次码。既有WS/下载/发现/音频端口不变；新收发使用控制端口+4，默认8903。若配对已成功但文件请求超时，请检查电脑专用网络的流转程序规则是否允许此端口。

- **文件：** 先完成手机私有发送副本，再进入可恢复任务；来源授权在准备阶段失效时需重新选择。新协议使用1MiB块、分块及完整SHA-256。暂停保留已确认字节，取消清理暂存副本，不删除原文件或已经接收的文件。
- **重启：** 打开应用并重新鉴权原电脑后恢复等待中的新任务；手动暂停仍需点继续。须匹配原地址、配对凭据与电脑身份，地址变化尚不能自动迁移旧任务。Android被强制停止后不会自行运行，也不会恢复麦克风。
- **文字：** 「正在保存待发」是保存中，「等待回执」不是已收到；确认后显示电脑已登记。自动文字最多五分钟；手动待发最多七天，自动尝试三次后保留，收发面板可重试或取消。更改目标或隐私规则仍会使旧自动事件失效。
- **保留期：** 电脑任务/回执窗口八天；若已创建的远端任务已清除或过期，显示过期并停止盲目重建，请检查对端后重新发送。源文件改变、校验失败或空间不足均不会确认完成。
- **空间：** 发送副本需要额外空间；下载暂存和最终发布会短暂占用两份空间。准备或保存未完成时有明确阶段，实际速度受设备与网络影响。

旧版对端继续使用原传输方式，无法从升级前内存中找回任务。恢复记录保留在当前设备，不随素材迁移包复制。实现、开源参考和测试边界见 [M48记录](performance/M48_RECOVERY_2026-10-18.md)。

## 4. 电脑素材栏与整理

- **取用：** 点击复制、拖出使用；图片／文字按空格预览，Esc 关闭预览。
- **筛选：** 分类、搜索、分组和标签可组合；「常用 ▾ → 保存当前筛选」保存规则，后续新增的匹配素材也会出现。
- **整理：** Ctrl/Shift 多选，点「整理…」、按 F2 或用右键菜单，编辑分组、标签和备注。批量操作只改勾选字段。
- **另存：** Ctrl+Shift+S 将选中素材保存到独立文件夹；文字为 UTF-8 TXT，同名自动编号，保留原件。另存用于交付文件，换机继续使用请导出迁移包。
- **修复来源：** 更多 →「素材来源管理与重新定位」，检查失效来源并选择新文件，或扫描指定文件夹后审核候选。
- **完整性：** 更多 →「素材内容完整性检查」，按已确认 SHA-256 基线检查变化；不能修复损坏文件或找回丢失原件。

快捷键：Ctrl+F 搜索、Ctrl+A 全选、Ctrl+C 复制、Ctrl+V 粘贴、Del 移除、Ctrl+Z 撤回、Esc 取消选择。移除索引与删除磁盘原文件是不同操作，操作前查看提示。

### 项目素材包（M56；M57增加手机入口）

1. 电脑选中需要带走的素材，点「更多 → 项目素材包：导出所选 / 合入」，导出项目 ZIP。包含所选正文、原件、收藏、分组、标签、备注及素材时间；不带电脑配置、口令、设备身份或原文件绝对路径。
2. 在另一台电脑打开同一入口，选择 ZIP，点「校验并预览」。全部原件通过 SHA-256 和 ZIP 完整性检查后，显示将新增、同包已登记及相同文字的数量；预览不修改索引。
3. 核对后点「合入当前库」。已有素材和设置保留；同一包重复导入会跳过已登记条目，相同内联文字复用现有素材并保留本机整理信息。不同包的文件不自动按内容合并，可另用重复检查核对。

每包最多1000项、16MiB清单、64GiB原件；纯文字正文最多262144字符，超限会拒绝而非截断。文件型文字始终携带完整原文件，卡片仅保留最多5000字符的已有预览。没有有效原件的文件条目须先修复来源。

校验预览会在当前库的 `project-imports` 准备原件并占用磁盘，取消或保存失败后保留供重试。M57从电脑容量窗口打开「项目暂存空间」，先扫描引用和阻塞情况，再选择回收未引用原件；回收区仍占空间，可恢复且不覆盖已有文件，没有自动清理。不要手工删除仍被索引引用的目录。提交前可取消，开始保存后需等待结果；只有本机索引落盘后才提示成功。若提示保存未确认，保留当前会话，重新预览并重试。预览后库变化或包文件被替换时会要求重新核对。

M57手机接收页可打开项目包功能：选择最多100项已同步素材，请电脑打包，完成后通过普通可靠下载保存ZIP；或者先将项目ZIP上传并登记到当前电脑，在对应ZIP上发起校验预览，核对数量后明确合入。待同步草稿须先处理，打包内容以电脑已经保存的值为准。旧电脑不显示这些能力。电脑作业最多4项、15分钟，仅保存在当前进程；关闭面板不等于取消电脑作业，电脑重启后需重新发起。ZIP已经生成后的文件下载仍按原续传任务处理。

### 手机常用搜索（M56）

在手机「接收」素材库组合搜索词、类型、收藏、分组、标签，点「保存此筛选」命名；从「常用搜索」应用、用当前条件更新或删除。每个已鉴权电脑/素材库最多10项，名称1–40字，搜索词最多256字。只在明确保存时写入，不记录输入历史；保存在此手机的加密本地记录，离线和重启后可使用，不同步到电脑，也不随PC迁移包带走。

普通清除离线索引会保留常用搜索；明确移除整个离线库时会一并删除该库的常用搜索。损坏记录保留，读取失败会停用常用搜索写入，不清空其他素材。输入采用250ms尾沿合并，新关键词可取消过时只读请求；不会取消已经提交的整理写入。

## 5. HEIC 与图片处理

设置 →「接收 HEIC 自动转换」：**PNG（默认）／JPEG／关闭**。按真实内容识别，扩展名误写为 `.png` 的 HEIC 也能识别。

设置自动保存，仅影响后续手机上传；旧图片需重新发送。转换后生成独立文件并加入素材库，原始上传文件保留。JPEG 质量 95，透明区域使用白底。

转换依赖 Windows 可用的 HEIF/HEVC 解码支持；失败时保留原件并提示。仅输出静态主图，不保证保留多帧、HDR 与全部元数据。缩略图正常不代表原文件格式一定能被第三方看图软件打开，改扩展名也不等于格式转换。

批量处理：选中图片 → 右键「处理图片」，选择 PNG/JPEG、最长边和质量。输出为独立副本，不放大尺寸，会清除拍摄元数据；参数可存为预设。结果大小取决于图片，转换后不保证更小。

## 6. 用手机做电脑麦克风

这是可选实验功能，不是流转内置语音识别。手机负责采音，流转负责传输，听写软件负责识别。

### 第一次设置

电脑麦克风设置顶部显示「电脑外放／流转写入／听写读取」三路卡片，并检查日常、媒体和通话的默认设备。打开时、窗口可见时每 10 秒及点击「重新体检」都会只读检查；音频服务开启时也可检查，不中断转发。M57还可从手机主动检查并修复流转的虚拟路由，见下方步骤。

如果提示「通话播放指向虚拟音频设备」，点「打开播放设备 · 修复外放」，将实体扬声器／耳机设为默认设备和默认通信设备。点「打开录音设备 · 检查输入」核对录音方向；只有听写软件跟随系统输入时，才需要改默认录音设备。读取失败会显示未知，已保存端点失效不会自动换成扬声器。体检不会自动改设置、安装驱动或开启录音，也不能代替实际听写验证。

1. 从 [VB-Audio 官网](https://vb-audio.com/Cable/)下载并自行安装标准 VB-CABLE，按官方要求重启电脑。驱动不随流转分发，采用 [Donationware 独立许可](https://vb-audio.com/Services/licensing.htm)，职业／公司用途应按官方条款付费。
2. 点击电脑流转标题旁音波图，或设置 →「手机麦克风」。刷新设备，输出选 **CABLE Input**，对应录音端选 **CABLE Output**；不要选 `CABLE In 16ch`，不要勾「仅诊断收音」。选择会保存在当前电脑，换设备或换电脑需重新配置。
3. 在 Windows 调整下表中的设备方向。流转不会自动更改系统默认设备。
4. 手机点「扫码连接全部功能」，扫电脑常规配对二维码并允许录音。正常流程无需第二次扫码，也无需电脑再点开始转发。没有驱动／配置失效时先完成电脑配置，再从手机音波图进入麦克风页点「连接当前电脑麦克风」。
5. 对手机说话，确认两端有实际波形，再启动听写软件的听写功能。波形或已连接提示不能单独证明语音识别成功。

| 设置位置 | 应选择的设备 |
|---|---|
| Windows 默认播放、默认通信播放 | **实体扬声器／耳机**，例如 Realtek 扬声器 |
| 流转的音频输出 | **CABLE Input**（虚拟播放端） |
| 流转的对应录音端 | **CABLE Output**（观察录音会话） |
| 听写软件的输入 | **CABLE Output**；若软件仅跟随系统默认输入，Windows 默认录音／默认通信录音也设为它 |

**扬声器与听写可以同时工作。** 不要把 Windows 默认播放设为 CABLE Input，否则系统声音会进入虚拟线，实体扬声器可能无声，也会干扰听写。不需要开启「侦听此设备」；其他软件若有单独的输出设置，也应选实体扬声器／耳机。

### M57：在手机检查并修复电脑音频

1. 先连接电脑素材服务，无需重新扫码。打开手机音波图，在波形下方找到「电脑音频」。
2. 点「仅检查 · 不改配置」查看当前状态。检查不保存流转设备偏好、不改Windows默认或音量；当前麦克风会话可继续运行。
3. 需要修复时，先结束当前麦克风会话，再点「检查并修复电脑音频」。电脑只在能安全确认唯一一组标准VB-CABLE设备时重新设置流转并开启待命服务；多组、信息不足、驱动缺失或正忙时会提示，不猜设备、不打断正在转发。
4. 保持手机在前台且面板打开，修复成功后使用现有连接取得新邀请，沿录音权限流程连接，不用再扫音频码。没有录音权限仍须明确允许；关闭面板或进入后台不会偷偷开麦。

「节能连接」下明确点击修复可临时开启麦克风；结束后继续保留节能偏好，不将其改成持续待命。修复只针对流转虚拟路由和服务，不改变Windows默认播放／录音、扬声器静音或音量，不安装驱动，也不能重新创建消失的Realtek声卡。设备识别核验驱动及同一硬件归属，不仅凭“CABLE”名称，16ch设备不会混选。

2026-10-25本机已安装新包，用户确认手机修复功能正常；仅检查前后流转偏好保持不变，修复前后Windows默认及活动端点静音／音量保持不变。这不等于听写精度、所有声音用途或实际省电效果已验收。

### M57：保存可用配置与偏差提醒

1. 开启转发、对手机说话，确认虚拟输出确实读取声音。流转会自动保留这组已验证的虚拟设备选择；收到声音本身不代表听写和扬声器都正常。
2. 实际播放一段电脑声音并完成一次听写，确认两者正常后，在麦克风设置点「外放和听写正常 · 保存配置」。此时记录本机流转设备、系统日常／媒体／通信六路默认端点以及外放音量／静音作对照，不保存声音或识别文字。
3. 以后设备、默认声音或音量变化时，流转会检查并提示可疑配置；正常改用耳机不直接当成错误。可通过上方Windows声音入口核对。
4. 确定是流转设备选择变动时，点「恢复流转设备选择」。恢复会先关闭音频服务，只还原原精确设备ID；不会改Windows默认、音量、静音、权限或自动跟随，也不会自动开麦。核对后自行开启服务。

原设备消失或驱动重装导致ID失效时不会用同名设备替代；请先恢复原驱动，或重新选择并验证。若Realtek等实体扬声器完全不在Windows设备列表，配置恢复无法创建声卡；先保存工作重启、检查设备管理器，仍缺失时再排查驱动。2026-10-25曾在用户重启后恢复外放，但具体根因尚未确认。保护档案仅留本机，不随迁移包导出。

### 日常使用、停止与设置

- 手机左上、电脑标题旁的音波图都能打开设置；波形来自实际音频。
- 关闭或下拉收起手机面板只关闭界面，**不结束采音**。
- 默认「安静省流量」按音量门限控制发送，并不识别人声。安静时只保留轻量心跳，手机仍采音；可选灵敏／标准／抗噪，或关闭省流量连续发送。设置自动保存，**下次开启会话生效**。
- 「停止转发」只停止发送链路，不等于释放手机麦克风；不用时在手机点「结束」，或电脑结束手机会话。会话持续待命，无固定闲置截止。
- 断线、重启不会自动开麦；普通素材重连不会恢复采音。需要用户重新从手机麦克风页连接。电脑锁定／睡眠会关闭音频服务。
- 「60 秒本机试音」只检查手机采音，不联网发送也不保存录音。「仅诊断收音」只验证电脑接收，不能供听写使用。
- 「实验自动跟随」默认关闭，需先校准听写开始→结束并验证录音会话；不是直接监听点击原听写按钮，兼容性不能保证。先确认普通转发听写可用再试。

音频当前在可信局域网明文传输，不保存录音。完整自动跟随、不同 ROM、锁屏／来电、弱网、首尾字表现与实际功耗仍需专项验证。

## 7. 升级、换电脑与备份

### 升级现有版本

- 电脑退出旧版后，替换完整 `app` 目录，保留旁边 `data` 及自定义素材目录。
- 手机使用同签名 APK 覆盖安装，安装后到无障碍设置将流转服务**关闭 → 重新开启**。使用 LSPosed 时重启作用域内目标应用。不要先卸载；签名不一致时先核实安装包来源。

### M57：索引历史与安全切库

电脑设置打开「素材库恢复与切换…」，核对当前库位置和已有历史。选择旧索引查看差异，或选择已有库安排切换；计划在下次启动执行，当前会话继续使用原库。可在退出前取消计划。不要手工移动正在使用的库目录。

索引历史每5分钟最多尝试保留一次，最多10份、总量128 MiB、单份64 MiB，不能替代完整备份。恢复前保留现索引并复核指纹，只还原条目和整理信息，不恢复已删除原件、Windows设置、设备身份或传输回执。计划与迁移导入冲突时会拒绝；恢复失败保留数据，不应反复手改配置强行切库。

### 换电脑

1. 旧电脑设置 →「迁移与备份（配置 + 素材）」→「导出迁移包…」，等待成功。
2. 将 `.liuzhuan.zip` 私下复制到新电脑，安装当前版本流转。
3. 相同菜单点「导入迁移包…」，确认内容，导入成功后退出并重新打开流转。
4. 新电脑生成新的配对二维码，手机重新扫码。HEIC 解码器与虚拟音频驱动需在新电脑另行准备。

迁移包含当前库引用的原文件、文字、收藏、缩略图、整理信息、常用筛选、图片预设及可迁移设置；不打包整个磁盘。不带旧窗口位置、旧数据路径、当前电脑的外部文件管理器 EXE 或音频设备 ID，也不备份手机的本地设置。

导入校验文件并创建独立素材库，重启后切换，不合并或覆盖原库。默认数据目录中保留 `config.before-import-*.json`；需回退时退出流转，先备份当前 `config.json`，再用对应备份替换，并保留原素材目录与 `imports` 目录。

**迁移包是未加密 ZIP，含素材与配对口令，不能上传到公开仓库或公开分享。** 缺失原件会报告；取消／校验失败不会切换素材库。麦克风设备偏好不随迁移包复制。

## 自动整理、目录订阅与快捷收集（v1.10.0）

**电脑：** 设置 → 自动整理、目录订阅与快捷收集。**手机：** 顶部“收集”。两端使用同一份电脑规则，请同时更新。

### 自动整理
1. 新建规则，选择素材类型、来源；可填写设备名称和素材名称关键词，留空表示不限。电脑来源名为“本机”，手机来源名为机型。
2. 填写目标分组、追加标签。已有分组保留，已有标签不丢弃。多条规则按列表顺序处理，首次命中的非空分组优先。
3. 点“预览最近50条”检查匹配；这不会修改素材。点“保存全部规则”后，只对之后首次收集的新素材生效。重复收集不会重写原整理。
4. 另一端保存后，先“重新加载”再编辑，避免覆盖对方更改。规则最多30条，每条素材最多20个标签。

手机接收页现可分页访问电脑完整素材库，显示分组、标签并搜索备注，支持单项及批量整理和实时元数据同步；详见下方M49/M52说明。只有未升级的旧电脑兼容路径仍使用最近50条摘要；规则「预览最近50条」是独立的规则预览预算，不是手机素材库上限。

### 目录订阅
- 电脑在“目录订阅”里选择独立来源文件夹。手机在同一页点“授权来源目录”，使用系统授权界面选择要收集的来源文件夹。**这不是接收路径设置；手机接收位置仍为Download/Liuzhuan。**
- 首次跳过旧文件，不递归子目录；之后新增或改写的文件稳定后才收集。最多10个来源，每个最多5000个直接子文件；临时文件忽略。原文件不移动或删除。
- 手机订阅只发送给授权时连接的电脑；换地址/电脑后需停止旧订阅并重新添加。离线、授权失效或部分文件管理器不发通知时，可回到流转或点“检查新文件”。
- 手机失败/取消的文件版本不自动反复重发，在“收发”显式重试。M48 已完成发送副本的任务可在重启后恢复，准备中的临时授权文件可能需重新选择；未知长度文件可手动选择发送。停止订阅不删除源文件或已收集素材。
- 迁移包携带整理规则，不携带来源目录路径、手机目录授权或订阅绑定；新设备要重新选择来源。

### 快捷收集与扫码
- 电脑“快捷收集”可收集当前剪贴板；全局Ctrl+Alt+V默认关闭，需要时勾选启用。若快捷键被占用会明确提示，原Ctrl+反引号保持不变。
- 手机“快捷收集”可在前台读取文字并预览，确认发送；也可选文件，或从其他应用的系统分享菜单发送。没有新增Windows右键菜单。
- 手机扫码页使用统一深墨绿/青绿色界面，在手机上固定竖屏，支持返回、手电筒及相机权限/占用重试。扫码仍是一次连接素材与麦克风，录音继续单独由系统授权。

## M51：容量、历史与大库（本地 v1.14.0）

电脑设置打开“容量、历史保留与清理预览”。先填天数和保护的最新条数，再点击扫描；默认30天、500条，收藏始终保护。统计为文件逻辑大小，不代表物理分配空间；托管副本统计`uploads/temp`，缩略图统计`thumbnails`，其他索引来源只读统计。更改条件后必须重新预览，打开窗口或保存策略不会自动清理。

两个动作分开：左侧选择历史索引后移除，文件原件保留并可从素材栏撤回；纯文字正文随索引移除，撤回仅限当前进程最多50步，长期保留请先导出备份。右侧选择未引用文件后移入本库回收区，每批最多200个。回收区仍占磁盘，可恢复最近批次且不覆盖同名新文件。展开回收明细，核对后再次点击“永久清空”并确认，才永久删除已回收的文件。

扫描跳过链接、当前索引和撤回来源、续传描述引用及HEIC原件。最近一天创建的文件也不会成为回收候选；有活动/暂停/待恢复任务时不执行文件回收。根目录、UNC数据目录、损坏记录或不完整扫描会阻止清理。扫描最多10万文件；只检查已知托管目录的直接文件，不递归清理用户子目录。文件元信息或库版本变化需重新预览。没有后台定时清理，不会删除外部原件；回收意图支持中断后恢复，不是跨文件系统事务保证。

保留参数可随配置/素材迁移包导入；回收区、待发与回执、隐藏历史记录不迁移。旧包缺少该可选字段时使用默认策略。迁移包仍只携带实际索引引用，不携带未引用的HEIC原件或回收文件；需要保留它们请另行备份。

手机收发页新增“容量与历史”：只读统计缓存及加密恢复数据，可清空8MB缩略图内存缓存。历史可选7/30/90天或全部，先预览再确认，仅移除已结束展示记录；进行中、暂停、待发、重试、续传描述与回执均保留。隐藏标记使用现有加密本地存储，最多2万ID；保存失败写日志，不声称已可靠落盘。原任务可恢复时仍会显示，已完成的描述不会反复带回已清理的记录。

手机最多保留1000条浏览摘要，继续加载会释放较早页，显示当前范围；“返回最新”或刷新回到最新窗口。全库搜索仍在电脑执行，原件按需下载。实时增量也受同一预算约束；旧版电脑兼容原列表，不承诺离线全库。

规模测试、模拟DPI和并发验证与真实设备结果分开，见[M51验证记录](performance/M51_STORAGE_SCALE_2026-10-18.md)。

## M50：麦克风恢复与节能（本地 v1.13.0）

手机左上音波图 → 麦克风偏好 → **即时待命 / 节能连接**。即时待命扫码后持续采音；节能连接会结束当前音频会话、释放麦克风和音频CPU锁，保留素材同步，此后扫码也不自动开麦。需要收音时在手机前台点“开启当前电脑麦克风”，结束后节能偏好仍保留。仅暂停传输或安静省流量仍会采音。

音频断线不必重新扫码：先确认素材已连接，在麦克风页点“重新连接当前电脑”。权限问题可直接打开系统应用设置；系统阻断需先取消系统麦克风静音或结束其他录音。电脑虚拟端点失效或锁定/休眠后，在电脑点“按原设备重试”，原ID仍缺失时先恢复驱动；不会换成扬声器。

自动跟随仍为默认关闭的实验选项：观察 → 校准 → 45秒内完成一次听写开启/结束 → 显示兼容后自行勾选。无法归属或未完成校准使用手动转发；手动停止、手机暂停或断线不会自动恢复。持续打开的录音流可能无法判断按钮状态。

采集/发送/读取计数和音频CPU锁状态仅用于排查，无录音保存；不能据此判断电池省电百分比。节能后不能在后台按需重新开麦，真实功耗/首尾字/完整听写兼容仍需专项设备验收。

## M49：历史连接与完整手机素材库（本地 v1.12.0）

两端更新后，在手机“历史连接”中可为电脑添加备注名。成功鉴权后，同一安装ID的新地址自动归并；连接历史时先限时发现并验证原口令证明。PC设置→“电脑名称与设备身份”可改名称，ID保持不变。未找到电脑、凭据变化或旧版没有稳定ID时，仍可能需要重新扫码。

手机“接收”切换为完整素材库，每页100条；点“加载更多素材”访问更早记录。搜索在电脑整个索引上执行，可叠加类型、收藏、分组和标签。每条右侧“整理”可编辑收藏、分组、标签和备注；“保存到电脑”成功后同步到电脑及其他连接手机。若提示冲突，草稿保留，可选择重新加载最新状态后再改，不会静默覆盖另一端。

只下载明确点击的文件，保存路径仍为Download/Liuzhuan。来源失效标记取自电脑最近检查；M49旧版断线只保留进程内摘要。M52离线浏览/编辑请按下节使用。新旧协议与M49验证边界见[M49记录](performance/M49_IDENTITY_LIBRARY_2026-10-18.md)。

## M52：手机批量整理与离线使用（本地 v1.15.0）

两端一起更新。在手机“接收→完整素材库”点击“批量整理”，勾选素材或“选本页”，每次最多100项。可批量收藏/取消收藏、设置或清除分组、追加/移除/替换标签；未选择的字段与备注保留。操作先可靠保存在手机，再同步原电脑；结果可在“待同步”中查看。

需要跨重启离线浏览时，连接原电脑后点击“保存离线索引”并确认。完整索引最多5万项、64MB、5个电脑素材库；下载中断、电脑内容变化或超限会保留旧索引。自动保存的最近浏览只标为“部分摘要”，不会冒充完整库。索引在手机加密存储且不参与系统备份。它是保存时快照，请在线后手动更新。

离线可搜索和筛选已保存索引，并整理收藏、分组、标签和备注；列表仍最多保留1000条摘要。图片、视频和文件原件/缩略图没有自动下载，需在线获取；完整保存且不超过16000字符的纯文字可离线点按复制，超长文字需在线获取。离线搜索仅覆盖已保存内容，不等同于搜索原文件全文。

每个库最多500条待同步更改。重连原电脑后，无冲突的字段自动合并；同一字段被双方修改或电脑已删除素材时保留草稿。打开“待同步→查看与处理”，核对电脑最新状态与我的更改后，可重新提交或放弃本机草稿。重复应答不会重复修改，不会自动重建已删除素材。

“清除离线索引”只清手机索引和文字副本，不删除电脑原件、接收文件或待同步草稿。清空索引且无草稿后可“移除此离线库”释放名额，下次连接可再次启用。旧电脑不支持离线更改重放，请更新电脑端。离线索引与草稿不进入迁移包。

## M57：离线增量更新与保留原件（本地 v1.20.0）

**更新索引：** 已有完整离线索引时，重新明确保存会优先取得当前电脑本次运行的增量；旧电脑、服务重启、游标过期或库变化时自动退回完整保存。中断、取消或校验失败不替换上次完整索引。索引始终是保存时快照，不是后台自动镜像；取消索引保存不删除本机草稿。重新编辑草稿只提交这次实际改动的字段，未编辑的电脑字段继续跟随远端。

**保留文件：** 在接收页文件卡片点「保留原件」并确认，主动下载并校验到手机私有区。顶部「离线原件」可查看状态、校验后打开、失败重试、取消固定及清理未被引用的中断副本。可选全机128/512 MiB、1/2 GiB预算，最多200项；下载预留和中断副本也计入。容量不足时调整预算或取消旧固定，不能绕过校验。

原件副本为私有明文文件，管理记录沿用加密存储，均排除系统备份。它们是保存时的历史快照，电脑文件改变后不自动替换，也不能证明仍为最新版。打开时仅向所选应用临时授予只读访问。取消固定只删本功能的私有副本，不删除普通 `Download/Liuzhuan` 接收文件或电脑原件；卸载流转会丢失私有副本，长期保存请另存到普通接收目录。离线原件不进入电脑迁移包。

本轮本地构建、生产链路、手机音频修复实测及隔离界面验证范围见[M57记录](performance/M57_RELIABILITY_OFFLINE_2026-10-24.md)；离线原件授权、其他ROM、锁屏和耗电仍待对应实机验收。
