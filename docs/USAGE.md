## 1. 安装与连接

### 准备两端

- **Windows 10/11 x64：** 下载 Releases 中的 Windows ZIP，完整解压，运行 `app/Liuzhuan.exe`。运行数据默认位于 `app` 旁的 `data` 文件夹，勿误删。
- **Android 16+：** 下载 Releases 中的 APK 安装。按需允许通知、扫码相机权限；手机麦克风另需录音权限。
- **网络：** 两端连同一 Wi-Fi，或手机开热点、电脑连接该热点。当前不支持公网或移动流量远程连接。

### 选择一种连接方式

| 方式 | 操作 | 麦克风行为 |
|---|---|---|
| 扫码连接全部功能 | 电脑开启局域网服务器，打开配对二维码；手机连接页扫码 | 完成素材连接后尝试音频连接，首次请求录音权限；无虚拟设备时提示配置，素材仍可用 |
| 搜索或手动连接 | 手机搜索电脑并点选填入地址，或手填 IP、连接端口；输入电脑显示的口令后连接 | 不因普通素材连接自动采音；需要时从音波图进入麦克风页主动连接 |
| 历史连接 | 手机点「历史连接」，选择曾成功连接的地址 | 重连素材；断线后不会自动恢复开麦 |

电脑可从设置或托盘菜单查看口令、地址与配对二维码。不要公开二维码或把口令放进反馈截图。

### 手机热点连接

1. 手机打开热点，让电脑连接。
2. 在电脑二维码窗口选择**连接手机热点的实际网卡地址**，重新生成二维码。
3. 手机重新扫码。换网前保存的历史地址可能已经失效。

如果电脑有 VPN、虚拟网卡或多个网口，选择能被当前手机访问的电脑地址，不要仅凭地址看起来像内网就选用它。部分路由器的访客网络／客户端隔离也会阻止设备互通。

默认端口：素材连接 TCP **8899**、文件 TCP **8900**、发现 UDP **8901**、可选麦克风 TCP **8902**。自定义素材连接端口后，文件端口为其加一，发现端口仍是 8901。防火墙只需放行所用功能在可信专用网络上的访问，不要直接关闭整个防火墙。

## 2. 文字与剪贴板

**先试手动发送，再配置自动同步。** 手机「发送」页输入并发送文字；电脑出现素材，说明基本连接正常。

### 普通手机，无需 Root

1. 如需自动捕获，按应用提示启用流转无障碍服务，并确认连接页「自动同步」已开启。
2. 在其他应用复制文字，再切回流转，发送最新剪贴板内容。
3. 也可选中文字，在系统文字选择菜单点「流转」；或在其他应用分享文字／文件给流转。

Android 限制后台读取剪贴板。某些应用暴露的文字选区可由无障碍捕获，但不能保证所有应用后台复制都自动发送；微信等受限场景可用分享、文字选择菜单或复制后切回。

### 已 Root 且装有 LSPosed

在 LSPosed 启用流转模块，勾选需要自动同步的目标应用，然后**强制停止并重新打开目标应用**。此模式旁路观察剪贴板写入，不轮询，也不修改来源应用的复制结果。Root 本身不等于已经启用模块和作用域。

### 暂停与排除

- 电脑：设置 →「剪贴板隐私与应用排除」，按进程名称配置。
- 手机：连接页「自动同步」卡片，按应用包名配置。
- 支持暂停 15 分钟、1 小时和手动恢复；两端规则分别设置。
- 排除名单非空时，无法确认来源的自动采集也会跳过。手动发送、分享和接收仍可用；排除不会删除已保存素材，也不能撤回已经发出的内容。
- 「均衡省电」默认关闭；开启后空闲允许休眠，锁屏同步可能稍慢，具体功耗未量化。

## 3. 文件收发与保存路径

**手机 → 电脑：** 发送页添加附件，或从文件管理器／其他应用分享给流转。电脑收到后会登记到素材栏。

**电脑 → 手机：** 将文件拖入电脑素材栏，手机「接收」页出现条目后点击下载。新下载文件统一保存在 `内部存储 / Download / Liuzhuan`，目录在首次接收时创建；旧文件保留原位置。

两端打开「收发」可查看当前会话任务、进度、速度和结果。手机下拉关闭收发面板不会中止任务。

| 操作 | 实际行为 |
|---|---|
| 安卓暂停／继续 | 暂停关闭传输，保留当前任务来源；继续时**从头重传**。原文件授权失效需重新选择 |
| 电脑暂停／继续 | 暂停当前连接，最多 90 秒；超时或断线需发送端重新传输 |
| 取消 | 中止可取消的传输阶段；已提交文字或已进入文件登记阶段无法撤回 |
| 打开接收目录 | 调用文件管理器浏览保存位置，不是重新选择保存目录 |

Android 可选择支持目录浏览的文件管理器，保存路径始终固定；若管理器不支持定位会提示更换应用，不弹出目录选择器。Windows 可自定义文件管理器 EXE 与 `{folder}` 参数模板，该偏好只保存在当前电脑。

**目前没有字节断点续传，也没有跨进程任务恢复。** 大文件采用流式传输，速度取决于设备与网络，不能保证固定耗时。「电脑已发送」与「手机已保存」是不同阶段，请以接收端结果为准。

## 4. 电脑素材栏与整理

- **取用：** 点击复制、拖出使用；图片／文字按空格预览，Esc 关闭预览。
- **筛选：** 分类、搜索、分组和标签可组合；「常用 ▾ → 保存当前筛选」保存规则，后续新增的匹配素材也会出现。
- **整理：** Ctrl/Shift 多选，点「整理…」、按 F2 或用右键菜单，编辑分组、标签和备注。批量操作只改勾选字段。
- **另存：** Ctrl+Shift+S 将选中素材保存到独立文件夹；文字为 UTF-8 TXT，同名自动编号，保留原件。另存用于交付文件，换机继续使用请导出迁移包。
- **修复来源：** 更多 →「素材来源管理与重新定位」，检查失效来源并选择新文件，或扫描指定文件夹后审核候选。
- **完整性：** 更多 →「素材内容完整性检查」，按已确认 SHA-256 基线检查变化；不能修复损坏文件或找回丢失原件。

快捷键：Ctrl+F 搜索、Ctrl+A 全选、Ctrl+C 复制、Ctrl+V 粘贴、Del 移除、Ctrl+Z 撤回、Esc 取消选择。移除索引与删除磁盘原文件是不同操作，操作前查看提示。

## 5. HEIC 与图片处理

设置 →「接收 HEIC 自动转换」：**PNG（默认）／JPEG／关闭**。按真实内容识别，扩展名误写为 `.png` 的 HEIC 也能识别。

设置自动保存，仅影响后续手机上传；旧图片需重新发送。转换后生成独立文件并加入素材库，原始上传文件保留。JPEG 质量 95，透明区域使用白底。

转换依赖 Windows 可用的 HEIF/HEVC 解码支持；失败时保留原件并提示。仅输出静态主图，不保证保留多帧、HDR 与全部元数据。缩略图正常不代表原文件格式一定能被第三方看图软件打开，改扩展名也不等于格式转换。

批量处理：选中图片 → 右键「处理图片」，选择 PNG/JPEG、最长边和质量。输出为独立副本，不放大尺寸，会清除拍摄元数据；参数可存为预设。结果大小取决于图片，转换后不保证更小。

## 6. 用手机做电脑麦克风

这是可选实验功能，不是流转内置语音识别。手机负责采音，流转负责传输，听写软件负责识别。

### 第一次设置

1. 从 [VB-Audio 官网](https://vb-audio.com/Cable/)下载并自行安装标准 VB-CABLE，按官方要求重启电脑。驱动不随流转分发，采用 [Donationware 独立许可](https://vb-audio.com/Services/licensing.htm)，职业／公司用途应按官方条款付费。
2. 点击电脑流转标题旁音波图，或设置 →「手机麦克风」。刷新设备，输出选 **CABLE Input**，对应录音端选 **CABLE Output**；不要选 `CABLE In 16ch`，不要勾「仅诊断收音」。选择会保存在当前电脑，换设备或换电脑需重新配置。
3. 在 Windows 调整下表中的设备方向。流转不会自动更改系统默认设备。
4. 手机点「扫码连接全部功能」，扫电脑常规配对二维码并允许录音。正常流程无需第二次扫码，也无需电脑再点开始转发。没有驱动／配置失效时先完成电脑配置，再从手机音波图进入麦克风页点「连接当前电脑麦克风」。
5. 对手机说话，确认两端有实际波形，再启动听写软件的听写功能。波形或已连接提示不能单独证明语音识别成功。

| 设置位置 | 应选择的设备 |
|---|---|
| Windows 默认播放、默认通信播放 | **实体扬声器／耳机**，例如 Realtek 扬声器 |
| 流转的音频输出 | **CABLE Input**（虚拟播放端） |
| 流转的对应录音端 | **CABLE Output**（观察录音会话） |
| 听写软件的输入 | **CABLE Output**；若软件仅跟随系统默认输入，Windows 默认录音／默认通信录音也设为它 |

**扬声器与听写可以同时工作。** 不要把 Windows 默认播放设为 CABLE Input，否则系统声音会进入虚拟线，实体扬声器可能无声，也会干扰听写。不需要开启「侦听此设备」；其他软件若有单独的输出设置，也应选实体扬声器／耳机。

### 日常使用、停止与设置

- 手机左上、电脑标题旁的音波图都能打开设置；波形来自实际音频。
- 关闭或下拉收起手机面板只关闭界面，**不结束采音**。
- 默认「安静省流量」按音量门限控制发送，并不识别人声。安静时只保留轻量心跳，手机仍采音；可选灵敏／标准／抗噪，或关闭省流量连续发送。设置自动保存，**下次开启会话生效**。
- 「停止转发」只停止发送链路，不等于释放手机麦克风；不用时在手机点「结束」，或电脑结束手机会话。会话持续待命，无固定闲置截止。
- 断线、重启不会自动开麦；普通素材重连不会恢复采音。需要用户重新从手机麦克风页连接。电脑锁定／睡眠会关闭音频服务。
- 「60 秒本机试音」只检查手机采音，不联网发送也不保存录音。「仅诊断收音」只验证电脑接收，不能供听写使用。
- 「实验自动跟随」默认关闭，需先校准听写开始→结束并验证录音会话；不是直接监听点击原听写按钮，兼容性不能保证。先确认普通转发听写可用再试。

音频当前在可信局域网明文传输，不保存录音。完整自动跟随、不同 ROM、锁屏／来电、弱网、首尾字表现与实际功耗仍需专项验证。

## 7. 升级、换电脑与备份

### 升级现有版本

- 电脑退出旧版后，替换完整 `app` 目录，保留旁边 `data` 及自定义素材目录。
- 手机使用同签名 APK 覆盖安装，安装后到无障碍设置将流转服务**关闭 → 重新开启**。使用 LSPosed 时重启作用域内目标应用。不要先卸载；签名不一致时先核实安装包来源。

### 换电脑

1. 旧电脑设置 →「迁移与备份（配置 + 素材）」→「导出迁移包…」，等待成功。
2. 将 `.liuzhuan.zip` 私下复制到新电脑，安装当前版本流转。
3. 相同菜单点「导入迁移包…」，确认内容，导入成功后退出并重新打开流转。
4. 新电脑生成新的配对二维码，手机重新扫码。HEIC 解码器与虚拟音频驱动需在新电脑另行准备。

迁移包含当前库引用的原文件、文字、收藏、缩略图、整理信息、常用筛选、图片预设及可迁移设置；不打包整个磁盘。不带旧窗口位置、旧数据路径、当前电脑的外部文件管理器 EXE 或音频设备 ID，也不备份手机的本地设置。

导入校验文件并创建独立素材库，重启后切换，不合并或覆盖原库。默认数据目录中保留 `config.before-import-*.json`；需回退时退出流转，先备份当前 `config.json`，再用对应备份替换，并保留原素材目录与 `imports` 目录。

**迁移包是未加密 ZIP，含素材与配对口令，不能上传到公开仓库或公开分享。** 缺失原件会报告；取消／校验失败不会切换素材库。麦克风设备偏好不随迁移包复制。

<a id="troubleshooting"></a>

## 8. 常见问题

| 问题 | 优先检查 |
|---|---|
| 扫码后连接超时 | 电脑服务器是否开启、二维码是否为当前网卡、是否切过网络、专用网络防火墙、VPN／路由隔离；同一 Wi-Fi 名称不保证互通 |
| 搜索不到电脑，但地址能用 | UDP 发现可能被隔离；直接扫码或手填当前地址连接 |
| 手机开热点后连不上 | 电脑先连接该热点，再用当前热点网卡地址重新生成二维码；不要沿用旧 Wi-Fi 历史地址 |
| 复制文字没自动到电脑 | 先测试手动发送，再核对无障碍、自动同步、隐私排除；严格后台复制需 LSPosed 模块与作用域 |
| HEIC 缩略图正常，原文件打不开 | 核对真实格式和 Windows 解码支持，开启转换后重新发送；不要只改文件后缀 |
| 手机下载后相册里没有 | 文件在 `Download/Liuzhuan`，用「打开接收目录」查看；图库是否索引由系统决定 |
| 手机有波形，电脑没有 | 检查音频连接、是否暂停／结束、安静门限；在设置查看链路诊断，必要时主动重连麦克风 |
| 电脑有波形，听写没声音 | 关闭仅诊断模式，核对 CABLE Input/Output 方向与听写软件实际录音输入；已接收不等于虚拟输出或识别成功 |
| 安装虚拟驱动后扬声器无声 | 把 Windows 默认播放和默认通信播放改回实体扬声器／耳机；流转输出仍保持 CABLE Input |
| 关掉面板仍显示麦克风占用 | 面板关闭不结束采音，打开麦克风页点「结束」 |
| 想断线后从上次字节继续传 | 当前不支持，重新传输；不要将暂停误认为持久断点续传 |

仍有问题可提交 [GitHub Issue](https://github.com/hxroo6/Liuzhuan/issues)，附两端版本、系统版本、操作步骤与脱敏诊断。分享前去掉二维码、口令、内网地址、设备标识、个人文字和文件路径；不需要上传录音或整个数据目录。
