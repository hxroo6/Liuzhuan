# M48 / v1.11.0：分类性能、断点续传与待发恢复

本地实施，尚未发布。改码前备份：`backup/1018-0650-M48-recovery`。依据当前源码和现行四份文档；开源参考与采用范围见 [参考记录](../research/RECOVERY_REFERENCES_2026-10-18.md)。

## 行为变化

- 电脑分类切换从逐项删除/移动改为一次集合重置；内容未变的缩略图通知不修改集合。网格、文字和音频列表均虚拟化/回收容器，文字独立分类仍保持全宽卡片。
- 缩略图只为已实现的卡片解码，后台并发最多 2，解码宽度 320；离开视口释放缓存，回收容器更换 DataContext 时重新关联。粘贴等明确动作仍可显式同步读取。
- 新协议按 1 MiB 分块、SHA-256 和服务端持久偏移续传。偏移冲突、错误校验和来源变化不推进断点；下载以完整 SHA-256 校验后才发布。
- 上传保存手机私有发送副本，断线不依赖临时分享 URI。电脑收到完整文件后，沿用 HEIC 转换和素材登记；索引与回执都落盘后才确认完成。
- 下载先保留私有部分文件，完整校验后写入固定 `Download/Liuzhuan`。持久保存 MediaStore URI，使用任务专用待完成名称恢复插入/发布中断；发布成功但状态未保存时校验同一 URI，不重复创建文件。
- 任务描述、已确认字节、暂停/取消和电脑控制修订可恢复。电脑控制通过已认证 WS 只通知对应客户端；客户端持久保存 X-Control-Sequence，跨重启拒绝迟到旧命令。重连补查一次状态，不做空闲轮询。
- 手机文字队列加密保存，发送前先写发送意图；固定请求号重试。手动文字自动重试次数用完后保留，供显式重试或取消；自动文字仍受五分钟期限及当前隐私规则限制。
- PC 登记意图 → 素材索引 → 成功回执按顺序落盘；回执缺失时重放关联原素材。已成功后用户主动删除素材，迟到重试不会把它复活。索引读取失败时拒绝覆盖和可靠登记确认。

## 数据和协议

- 既有 WS / HTTP / UDP / 音频端口不变；新收发端口为控制端口 +4，默认 8903。握手声明 `resumable_transfer_v1`、`durable_receipts_v1`、`resumePort`、`serverId`；客户端 hello 增加本机 UUID。二维码不增加一次扫描。
- 每个 HTTP 请求均校验配对鉴权和客户端 ID。仍为已选择的明文局域网方式，没有宣称新增长期信任、公网或 TLS 功能。UUID 是恢复关联，不是第二个认证凭据。
- PC：`transfers-v1/` 保存偏移、暂停/取消及上传部分文件；`receipts/` 保存幂等状态；`transfer-history.json` 保存有界界面历史；索引素材附带登记关联键。历史读取异常保留原文件。收发元数据以原子替换保存，文件数据先 Flush 再推进偏移。
- Android：`noBackupFilesDir/recovery/` 保存本机 UUID 与加密记录，`transfer-payloads/` 保存私有发送副本/下载部分文件。密文使用 AndroidKeyStore AES-GCM；恢复记录不进入换机包。正文不写诊断日志。
- 迁移只带用户素材、整理规则和已支持配置，不带任务、回执、设备 UUID、来源授权或登记关联键。

## 保留与失败边界

- 两端更新后，**新建且发送副本已准备完成**的任务可恢复；升级前内存任务无法补出丢失的描述。来源仍在准备且临时授权已失效时需要重新选择。
- 自动文字最多 50 条、五分钟；手动待发最多七天。最多自动提交三次，手动请求随后等待显式重试。切换目标/配对凭据/设备身份和隐私规则仍可取消旧自动待发。
- 服务端回执和任务元数据保留窗口八天，在新任务创建时清理；回执最多 10000 条、传输元数据最多约 1000 个。容量满明确拒绝，不提前丢弃窗口内的有效去重凭据。客户端已创建过的远端任务若不存在，标记过期并停止自动重建，避免保留期后盲目重放。旧版内存回执不能安全跨重启重放。
- 手机最多 1000 个恢复描述，保留约 40 个已完成/取消描述；未完成和手动待发不因普通历史淘汰而失去操作入口。成功/取消清理私有副本，不删除原始来源或已经保存的接收文件。
- 发送快照需要额外本机空间；下载暂存与发布也会短暂占用两份空间。来源报告大小或修改时间时核对准备前后变化；提供者未报告修改时间时不能证明源文件从未被同大小改写，实际传输以完成的私有快照为准。
- 应用启动/原电脑重连恢复等待中的任务，手动暂停保持暂停。Android 被强制停止后须先打开应用；不恢复麦克风采集许可，不新增后台轮询或保活锁。
- 未更新的对端继续走旧协议：安卓从头重传，电脑暂停当前连接最多 90 秒；界面说明区分新旧方式。网络/端口不可达会保留断点并提示重试，不会保证网络条件始终可用。

## 验证范围

- `scripts/RecoveryChecks/Run-RecoveryChecks.ps1`：生产 HTTP/WS 服务与 Android 传输器；跨 JVM 客户端重启、隔离服务器强制结束、偏移/校验冲突、暂停取消、索引落盘后回执中断、下载发布中断、不同目标与迟到控制。
- Android 传输器运行在 JVM 平台 IO 适配器上，真实运行生产状态机与 OkHttp，并与生产 C# 服务通信；AndroidKeyStore、MediaStore 和系统进程生命周期是平台替身，**不等于 Android 真机验收**。
- `scripts/DesktopUiChecks` 性能模式：10000 条素材、七类循环切换，检查视口容器数、全宽文字布局、选中保持及缩略图离屏释放/重新加载。离屏计时包含调度等待，不能当作真实 GPU 帧率。
- 另跑剪贴板回执、隐私/损坏配置、功耗与传输槽、素材镜像、DataStore、迁移和既有桌面界面回归。
- 无线调试恢复后，正式签名 Distribution 包已覆盖安装到 Android 16 手机；v1.11.0 冷启动、连接电脑与收发面板通过。128 MiB 独立测试文件下载至 34 MiB 时暂停，强制结束应用后重开，任务及进度仍保留；重新连接原电脑并显式重试，从原断点继续。最终保存到固定 Download/Liuzhuan，完整 SHA-256 与原件一致；再经系统来源文件选择器回传电脑，服务器持久状态 stored、素材登记及完整 SHA-256 均通过。

- 10000 条素材离屏测试：实际网格容器 4 个，切换中位 45.6791 ms、P95 63.0122 ms、最大 68.0493 ms；包含调度等待，不代表屏幕帧率。性能检查 36 项通过。
- 恢复专项：生产 C# 服务 31 项、生产 Android 传输器跨三个 JVM 的 16 项断言通过，包含校验/偏移冲突、进程中断、持久控制次序、过期保护与准备时取消。
- 既有回执检查 C# 14 项及 Android 52 项、隐私 82 项、AES-GCM 22 项、功耗/传输 46 项、接收镜像 28 项通过；DataStore、迁移、整理和桌面回归均通过。并行构建负载下既有动画中间态计时曾失败一次，隔离重跑完整回归通过，未修改动效掩盖问题。
- Android Debug 与 Distribution 均构建通过；Distribution 签名与上一版一致。Windows 自包含 Release 发布通过；真机测试产生的两条独立素材均经名称、路径和 SHA-256 核对后清理，480 条原有素材全部保留，电脑端已重新启动。手机上本轮生成的测试文件也已清理，任务历史保留供核对。
- 电脑产物：`app/Liuzhuan.exe`，2026-10-18 07:57:31；Android：`AndroidApp/Liuzhuan-M48-signed.apk`，2026-10-18 07:57:45。本地版本 v1.11.0，未推送或发布 GitHub。
