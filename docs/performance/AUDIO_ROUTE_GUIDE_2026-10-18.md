# M46 音频设置向导与路由体检

日期：2026-10-18。电脑端本地版本：1.9.1。用户授权完成规划第一项；本轮未开发续传、数据版、加密或其他规划项目，未发布 GitHub/Release。

## 完成内容

- 麦克风设置顶部新增三路卡片：电脑实体外放、流转虚拟播放端、听写虚拟录音端；按名称清楚解释 CABLE Input → CABLE Output，不把“输出”一词混为系统扬声器。
- 后台只读枚举当前、禁用与断开端点，分别读取 Windows Console、Multimedia、Communications 的默认播放和录音，共六种默认角色；能发现“普通播放正确、通话播放仍是 CABLE”。
- 区分未选择、保存设备不在列表、端点被禁用/断开、未安装标准 CABLE、读取失败的未知状态、非典型设备、16ch 与设备对不匹配；每应用单独指定输入与系统默认不同只作条件性说明，不误判故障。
- 提供重新体检、Windows声音设置、播放设备、录音设备固定入口，由用户在系统面板确认修改；不自动改默认设备，不安装驱动，不启动录音或合成声音测试。
- 窗口可见时每10秒刷新，手动检查和设备刷新共用在途扫描；音频服务启用时仍可检查，不重绑当前设备，不重启服务。关闭停止计时且忽略迟到结果。
- 体检不会自动把已失效保存ID换为扬声器或其他虚拟端。修改选择/模式即时重算快照，偏好仍沿原开启服务后保存语义。
- 复制脱敏诊断增加受控问题代码和标题，不复制设备名称、端点ID或异常原文。体检未完成明确显示未知，不把配置正确宣传为虚拟线连通、应用输入正确或ASR成功。

## 检查

- 18项路由判断：三种播放角色分别误选、无默认、枚举失败与真实缺失区分、保存ID失效/禁用、不回退、非典型实体选择、16ch、默认录音差异、诊断模式与分享字段。
- 19项生产WPF离屏检查：三路卡片与通信误选提示、固定设置入口、脱敏诊断、字号/颜色、原按钮状态、标题波形位置；检查截图使用虚构设备与隐藏网络地址。
- 原71项音频回归通过：统一扫码、许可/代次、静音门控、缓冲、PCM证据、会话跟随策略、错误令牌、暂停/结束及断线边界。
- PC Release build、自包含win-x64 Rebuild与publish通过，0警告/0错误。发布前关闭本工作区旧进程并备份程序目录；无额外残留构建dotnet进程。
