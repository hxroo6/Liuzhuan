# M38 历史连接

用户要求安卓连接页增加历史连接选项。当前交付包含 M37 热点识别修复，电脑程序本轮不变。

## 功能

- 只在当前 WebSocket 鉴权成功、收到 welcome 后记录；失败连接和扫码填入本身不记入历史。最近 20 个地址，按 host + port 去重，重新连接更新时间与凭据。
- 历史列表显示地址、端口和上次连接时间，支持点选重连、删除、确认清空。记录跨进程持久化；删除历史不影响当前会话、素材和原有当前目标设置。
- 独立 DataStore 存储历史，历史口令为 AES-256 / GCM 密文，随机 IV、本机 Android Keystore 密钥；没有口令明文展示或导出入口。既有 SettingsStore 当前目标格式保留。
- 恢复沿原连接路径，保留最新省电、隐私、文件管理器偏好；损坏或无法解密时明确提示重新扫码，历史写入失败不影响连接。
