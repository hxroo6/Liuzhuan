# M39 手机麦克风手动实验版

版本：两端 `1.9.0-preview.1`；Android versionCode12。局域网明文首版，由用户“开始开发，先不做加密”授权。实现原生平台采音与虚拟设备输出，没有引入 MicYou/AndroidMic/VoxMic 应用、插件或业务源码。

## 已实现与操作

1. 电脑设置 → 手机麦克风，刷新并明确选择相连的虚拟播放端/录音端，例如 CABLE Input → CABLE Output。开启服务。未安装驱动时先由用户安装兼容驱动；程序不静默安装或更改系统默认设备。
2. 选择电脑实际 Wi-Fi/以太网地址，生成两分钟有效的专用二维码。
3. 手机右上角麦克风 → 扫码 → 确认局域网明文 → 系统录音授权 → 开启15分钟会话。手机前台真正启动 microphone FGS 与 AudioRecord 后可放到后台；仅使用确认的内置麦克风。
4. 电脑开始转发，等待有效音频帧。Codex选择对应虚拟录音端，使用原听写。流转不做ASR；识别联网、结果和服务行为遵循Codex自身功能。
5. 停止转发只停止传输/电脑输出，手机仍采音待命。手机可暂停、允许电脑再次请求、结束；电脑可结束手机会话或关闭服务。关闭设置窗口不会结束音频服务，手机通知明确提示持续采音并提供结束按钮。

当前只支持**手动转发与只读录音会话观察**，未开放自动跟随。观察器使用MTA线程、会话实例与短通知入队，250ms核对已跟踪会话状态；候选Codex PID不代表可信独立归属。未把音频会话状态当成原按钮事件，也未使用界面Hook/注入。

## 通道与资源语义

- 音频独立于素材连接：Kestrel WebSocket TCP8902 `/audio`，仅接受私网IPv4/本机；固定消息上限8KiB、认证5秒超时、最大8个连接、仅一个已认证手机。随机24字节邀请、单次使用、两分钟有效、重启作废，不持久化。
- 按用户要求没有TLS、音频加密或长期配对。随机邀请防误连接，不抵抗局域网窃听；没有公网/手机流量模式。未自动更改防火墙。
- 控制与二进制帧同一连接。PCM S16LE mono16kHz，每20ms一帧640字节，头44字节：`version:u16 flags:u16 generation:u64 sequence:u64 sampleOffset:u64 captureTimeUs:u64 sampleCount:u32 payloadLength:u32`。头为网络序，PCM小端；captureTime为明确标记的手机单调时钟估计，不与电脑时钟直接相减。
- 首版消息：`hello/welcome/status/start_forward/forward_started/stop_forward/forward_stopped/lease/paused/end_session`。版本两端成对定义于 AudioProtocol.cs/kt。代次单调增加；停止先关闭输出再废止代次，旧ACK/数据不能复活输出。TCP连接内重复启动不创建第二个采集器，停止幂等；首版无跨连接请求恢复。
- 手机发送队列约100ms阈值，超过即结束连接，避免滞后追赶；电脑环形缓冲硬上限200ms，溢出丢旧保新，约60ms起播，欠载补静音，停止清空。WASAPI共享模式、持续格式适配，显式端点，不回退默认扬声器。
- 需求租约5秒，PC每秒续约；手机未收到控制5秒结束，电脑未收到手机状态6秒、开始ACK3秒或正在接收却连续2秒无音频时结束连接。延迟为设计看门狗，系统冻结和原生释放可能延后，不承诺硬实时。
- 手机15分钟到期或闲置60秒释放；系统静音、录音策略阻断、未批准路由、断网均结束，重连需重新扫码/确认。PAUSE/RESUME不能冷启动采集。单实例资源护栏：原生释放异常时阻止第二个采集器，明确显示异常。
- 手机独立、有限15分钟CPU锁；通知只随状态变化更新，UI计数约1Hz，不每帧触发重组。采集read/stop/join/release、网络和PC音频初始化不在UI线程。电脑锁定/睡眠会关闭音频服务。
- 不存录音、令牌或麦克风许可到素材迁移包；原剪贴板、LSPosed广播、签名、素材快照/增量与收发语义保留。
