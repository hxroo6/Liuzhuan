## 本轮完成

- 电脑选中素材后「更多 → 项目素材包：导出所选 / 合入」，导出白名单项目ZIP，另一电脑先完整校验并预览，再加入现有库。带正文、完整原件、收藏、分组/标签/备注和素材时间，不带配置、凭据、外部源路径、设备身份、旧基线或远端回执关联。
- 每包最多1000项、16MiB清单、64GiB原件；显示名称最多256字、纯文字正文最多262144字符，超限拒绝。文件型文字保留完整原件，另带最多5000字已有预览，不自动解码原件。规范来源路径只复制一次；清单在序列化期间即限额，避免先分配整份超大JSON。
- 路径、大小、成员白名单、来源时间、元数据、SHA-256和ZIP CRC32验证；重复大小写路径、额外成员、越界/保留名/链接路径拒绝。显式准备目录以包UUID与清单指纹绑定，同包重试复验ZIP和原件，不把mtime当内容真值。导出只有关闭并强刷.partial后才公布成品。
- 专用DataStore批次入口完整验证后单Reset合入，保留原库对象及顺序，逐新项发连续LAN序号，不执行自动整理规则。内部project键识别重导；相同内联文字保留本机收藏及整理，只追加内部重试键，跨包文件不按内容自动合并。原包/库代次再次核对，Flush成功后才确认；提交后不能以取消撤销已经可被持久引用的原件。
- 手机「保存此筛选 / 常用搜索」按已鉴权电脑+库保存命名条件，最多10项/库，显式保存/应用/更新/删除，支持离线及跨进程恢复。复用现有加密LibraryRecords/noBackup，不记键入历史、不与电脑常用筛选同步、不进PC迁移包。损坏记录保留，只禁偏好写入，不影响素材库。
- 手机分页使用collectLatest替换过时只读load子任务、250ms尾沿输入合并，释放旧await的请求锁，不取消独立元数据写入/后台发送。外部应用条件前核对epoch及最新文本，正常输入的选区/IME组合态不因同文本回写而重建。

## 数据保护与兼容边界

- 改动前备份 `backup/1023-0207-M56-project-pack-search`，437个源码/配置/文档文件SHA256一致。测试只使用F盘临时合成库、文字、原件和归档；没有操作手机、读取真实素材或清理真实资料。
- 项目包原件准备会占用当前库project-imports空间。取消、未完成包及保存失败保留可重试原件，不自动回收；现容量页未单列全部未引用准备数据。原件被当前内存/索引引用后不可盲删，不能把准备目录与索引当跨文件事务。
- 保存失败可已在当前会话中合入，界面明确“尚未确认”，须重新预览并重试；不回滚覆盖期间收到的新素材。不同包的文件可再通过M55重复检查核对，不自动合并。
- 项目包只支持普通本地非根目录的目标库，UNC、链接路径拒绝；64GiB是预算，不是已用64GiB样本验收。图片/音视频派生信息按既有有界加载重建，旧完整性基线不当新信任。

- 未完成真实手机IME、KeyStore/重启、触摸布局、弱Wi-Fi、锁屏/来电、电池A/B或多屏DPI验收。本轮不改剪贴板Hook、事件评分、发送进程scope、录音许可、签名配置、端口或协议，不新增依赖、闲置轮询、唤醒锁。
